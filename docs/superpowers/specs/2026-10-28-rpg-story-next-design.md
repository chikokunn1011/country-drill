## 1. 今の冒険（確認したこと）

- ダンジョン7つ（`rpg-core.js` の `DUNGEONS`）: 南アメリカ → オセアニア → 北・中央アメリカ → ヨーロッパ → アジア → アフリカ → 地図喰いの巣（全世界）。各 F1〜F4＋ボスの5フロア、全35フロア

- 出題の形は国旗→国名（f2n）・国名→国旗（n2f）・場所→国旗（m2f）。ボスは旗の枚数ぶん当てる

- 冒険ランキング（Supabase の `rpg_players`）はレベル・ダンジョン数（0〜7）・フロア数（0〜35）。サーバー側の確認関数 `rpg_record_ok` がこの上限で弾く

## 3. ストーリー（文の案）

**地球クリア（地図喰いを倒したとき）**
> 地図喰いをたおすと、195の旗が空に舞いもどった。
> でも、地図喰いのいた場所に、鏡のような裂け目がひとつ残っている。
> のぞきこむと、そこにはそっくりだけど少しちがう、もうひとつの地球があった…

**第2章 鏡の地球（はじまり）**
> 鏡の地球では、国旗がみんな似たものに化けている。
> 本物の旗を見分けられるのは、旅人のきみだけ。
> 鏡の地図喰いをたおして、ふたつの地球をつなぐ裂け目を閉じよう！

**第2章クリア**
> 裂け目が閉じる直前、鏡の地図喰いがさけんだ。「母さま、あとはたのむ…」
> 夜空を見上げると、星がひとつ、またひとつと消えていく。
> 地図喰いを生んだ「星喰い」が、宇宙から地球をねらっていたんだ。

**第3章 宇宙（はじまり）**
> 星喰いは、星をひとつずつ飲みこみながら地球へ近づいている。
> 星には、地球の国のなかまたちの記憶が眠っている。
> 宇宙から地球を見下ろして、国の場所を思い出し、星喰いを止めよう！

**エンディング（星喰いを倒したとき）**
> 星喰いが消えると、飲みこまれた星たちがいっせいに光りはじめた。
> 地球も、鏡の地球も、宇宙も、もう安心だ。
> でも旅は終わらない。英雄の塔のてっぺんは、まだだれも見たことがない――

## 6. 英雄の塔

### 6.1 ルール

- 地図喰いを倒すと開く。何度でも挑める。始めると1階から
- 1つの階 ＝ ストーリーの通常フロアと同じ大きさのバトル1回（敵の HP も同じ考え方で、正解約5回で勝ち）。チコ決定（2026-10-28 11:14）
- **HP は階をまたいで持ち越し**。階を上がるたびに最大 HP の 10% だけ回復
- **10階ごとに中ボス**（旗の枚数 = 5 + 階/10、上限12）。中ボスを倒すと HP 全回復
- HP が 0 になったら終わり（思い出して復活は無し）。その回に届いた階が自己ベストを超えたら記録
- 途中でやめる・ページを閉じると、その回はそこで終わり（届いた階は記録する）
- 出題は全世界から。**21階から**鏡の地球の「似た旗の選択肢」、**51階から**宇宙の「場所多め」を混ぜる。チコ決定（2026-10-28 11:14）
- 仲間・編成は今と同じものを使う。地域ボーナスは全世界ダンジョンと同じく全員にかかる

### 6.2 強さ

- 塔の f 階の推奨Lv = 1 + floor((f−1)×1.0)。上限は無いので、どこかで必ず負ける（レベル・仲間・正確さでどこまで行けるかの勝負）
- 敵の強さの式は今の `enemy()` と同じ考え方で、ステージ番号のかわりに階の推奨Lvを使う

### 6.3 ごほうび（コインの稼ぎすぎを防ぐ）

- 1階ごとに 5 + 階 コイン（ストーリーより少なめ）
- 自己ベスト更新で 1階につき 20 コインのボーナス（はじめて届いた階だけ）
- 10・25・50・100階到達でバッジと称号（例: 塔の見習い・塔の戦士・塔の勇者・英雄）

### 6.4 ランキング

- 冒険ランキングに3つ目のタブ「英雄の塔」（最高到達階 → レベルの順、上位50人）
- `rpg_players` に `tower int not null default 0` 列を足す。登録・更新の関数は今と同じように新しい名前で作り、古いものは消さずに残す（2026-10-27 と同じやり方）

## 7. レベルと強さの調整

- 旅人のレベル上限を **50 → 99** に上げる
- 推奨Lv の式は章ごとに伸び方を変える（今のままだと第3章の最後が Lv125 になって重すぎる）
  - 地球（s=1〜35）: 今のまま（Lv1〜41）
  - 鏡の地球（s=36〜70）: 41 + (s−35)×0.8 → Lv42〜69
  - 宇宙（s=71〜105）: 69 + (s−70)×0.85 → Lv70〜99
- ストーリーのコイン（勝ち: 10+2s、初クリア3倍）は今の式のままで、後半ほど自然に増える
- 数字は全部 `TUNING` に置き、実装後に遊んで直す前提

## 8. セーブとデータ

- `DUNGEONS` に章の番号 `ch`（1・2・3）を足し、14個増やす（全21）。`floors`・`gauge` はダンジョン id ごとなので形は変わらない
- 開く条件は今の `unlocked()`（前のダンジョンのボスを倒したら次）をそのまま21個に延ばす。ただし第2章の1つ目は「地図喰いを倒した」、第3章の1つ目は「鏡の地図喰いを倒した」
- 地図喰いの巣ができたあとの「全クリア！」表示は、星喰いを倒したあとに移す
- 塔のセーブ: `tower: { best: 0, paid: 0 }`（best＝自己ベストの階、paid＝更新ボーナスを払った階）。1回の挑戦の途中はセーブしない
- 見たストーリー画面: `story: []`（見た章の終わりの id）。同じ画面を二度出さない
- セーブの版 `VERSION` は 1 のまま（足す項目は sanitize で埋まる。知らない項目を残す仕組みがあるので、古い版に戻っても消えない）
- ランキングの上限: `rpg_record_ok` を lv 1〜99・ダンジョン 0〜21・フロア 0〜105・塔 0〜100000 に広げた新しい関数にする（本番DBの変更はチコのOKが要る）
