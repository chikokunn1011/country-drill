## 0. まとめ

- **通貨はコイン1種類だけ。** いつものクイズで稼ぎ、使い道は **旅人のレベルアップ** と **国旗ガチャ** の2つ。
- **戦闘も4択クイズ。** 正解すると攻撃、まちがえると反撃される。レベルを上げると「倒すのに必要な正解の数」が減り、「まちがえても大丈夫な回数」が増える。レベルで知識の代わりはできない（ボスは旗の枚数ぶん、必ず正解が必要）。
- **仲間は国そのもの（195枚のカード）。** ガチャで出るほか、**同じ国に5回（別々のゲームやバトルで）正解すると自動で仲間になる**。だから、覚えることとカード集めが同じゴールになる。
- **ダンジョンは6地域＋最終の7つ。** それぞれ F1〜F4 とボスで5フロア、1フロアは1〜2分。地域の国を面積の大きい順に4つに分けて、F1 から F4 に割り当てる（**小さい国は最深部にいる**）。ボスの旗は**自分の苦手な国**から選ぶ。
- **学習のループ:**
  - 戦闘での正解・不正解も既存の `misses` に書き込む
  - 苦手な国は戦闘にまぜて出す
  - 力尽きても、まちがえた国を思い出せれば復活できる
  - 毎日「手配書」で3か国を出す（間をあけた復習になる）
- 新しいファイルは5つ: `rpg-core.js`（計算だけ。テストできる）、`rpg.js`（セーブ・イベント・冒険ホーム）、`rpg-cards.js`（ガチャ・仲間・シェア・演出）、`rpg-battle.js`（戦闘）、`rpg.css`。**index.html の変更はフックだけで約40行**。
- 画像ファイルは使わない。国旗は今ある `flag(a)` の SVG、モンスターとアバターは絵文字（Unicode 11 まで）、そのほかは CSS で描く。

**3つの約束（実装でも守る）**
1. **戦闘での行動はすべて出題。** 答えずに先へ進む方法はない。
2. **ミスは必ず復習になる。** まちがえるたびに答え合わせ（国旗・国名・首都・地図）を出し、自分で［つぎへ］を押すまで待つ。
3. **国に優劣をつけない。** レア度はカードの枠の金属で表す（ブロンズ / シルバー / ゴールド）。どの国にも★1〜★3がある。国旗は揺らさない・破らない・逆さにしない・ダメージを受けさせない。

### 0.1 v2 で直したこと（完成度チェック）

- **苦手の判定:** 既存の `misses` は「正解で −1」なので、練習で「まちがえる→あとで正解」すると0に戻り、苦手が残らなかった。RPG 側に `wk`（苦手の印）を持ち、「まちがえたら付く／**別のゲームで**ヒントなし一発正解したら外れる」にした。克服・苦手×2・ボスの旗・手配書はこれを使う（§8）。
- **克服の量産を止めた:** 同じゲームの中の「まちがえ→やり直しで正解」では克服にならない（一発正解が条件）。
- **はじめて正解ボーナス:** バトルで先に `mb` のビットが立つと、クイズの +20 がもらえなくなっていた。支払い済みを別の `fe` で持つ。
- **受け取りの二重払い防止:** `paid` を「sid → 払った額」にし、`pagehide`/`visibilitychange` で途中まで受け取ったあとに結果が来たら**差額だけ**払う（bfcache から戻ったときに後半のコインが消えていた）。
- **クリアボーナスにも目減り:** 短いゲーム（5問）を同じ国で回すと、目減りしないクリアボーナスだけで稼げた。ボーナス×その回の国の目減りの平均にした。
- **数字の食い違い:** 通常の敵は「コンボがあっても5回」（1.0+1.1+1.2+1.3=4.6<5）。結果画面の例の合計。ペースの表（モデルで計算し直した: 毎日15分で地図喰いまで約3週間）。
- **文化をモンスターにしない約束との矛盾:** 🗿モアイ（ラパ・ヌイの文化財）→ 🐆 ジャガー王、🛡️さまよう鎧 → 🕷️ 古城の大グモ。
- **ガチャの運をほめるバッジ（rpg-gold）を削除。** 「引いた回数のバッジなし」の方針と合わせた。
- **スマホ:** 360×640 でバトル上部の sticky が高すぎて選択肢が隠れる → 短い画面では1行の小さいヘッダーにする。正解後の自動送りの直後のタップが次の問題の選択肢に当たる（ゴーストタップ）→ 出題直後 250ms は押せない。トップバーのコインは小さく。
- **PC:** `container-type: size` は高さを決めないと0になる → ステージに `height` を明示。まちがえたときの答え合わせは選択肢の場所に入れかえて、1280×720 でもスクロールしない。
- **はじめての人の迷い:** 「余裕／ちょうど／きびしい」を Lv だけでなく仲間こみの「倒すのに必要な正解・まちがえてOK」で判定。ガチャの地域は次のダンジョンの地域を最初から選んでおく。ボスの登場画面で旗のしくみを1行で説明。coin と pt の見分け（初回だけトースト）。
- **セーブの堅牢さ:** `v` がないオブジェクト、`v<1`、移行関数の抜け、`__proto__` などのキー、NaN、配列/オブジェクトの取りちがえ、localStorage が使えない・満杯、引き継ぎコードの長さと形式を具体的に決めた（§9）。引き継ぎコードに `misses` も入れられる。
- **index.html のフック:** `startGame()` の先頭で、終わっていない前のゲームを `endGame('quit')`（H4a）。`rpg:levelup` は `{lv, from}`。

## 1. コンセプトと世界観

**タイトル: 国旗クエスト**（サブタイトル: 地図喰いから世界を取りもどせ）。ホームのボタン名は **「冒険」**。

> 世界地図をかじる怪物「地図喰い（ちずくい）」と、その手下のモンスターたちが、世界中の国旗を持っていっちゃった。
> 旅人のきみは、クイズで集めたコインで力をつけ、国のカードの仲間といっしょに6つの地域を旅する。
> 国を思い出すたびに、国旗がひとつ戻ってくる。地図喰いの巣で親玉をたおして、195の旗を取りもどそう！

- 最初に冒険を開いたときに、この3行とアバター選びを1画面で出す。物語はこれと、モンスターの名前だけ。
- **敵は動物・自然・伝説の生き物だけ**にする。人・民族・文化はモンスターにしない。
- モンスターは、布をかぶせた国旗（灰色の四角に「？」）を持っている。正解すると布がめくれて本物の国旗（`flag(a)`）が見え、旅人のほうへ戻ってくる。攻撃を受けるのはいつもモンスターで、国旗ではない。
- **地図帳らしい見た目:** ダンジョンは地図帳の図版として見せる（`PLATE 01 · SOUTH AMERICA` のような等幅の小見出し）。紙と等高線のテクスチャ、見出しのフォントは今のものを使う。

## 2. コアループ

```
 いつものクイズ（4モード × 練習 / 挑戦 / タイムアタック × 地域）
   │ 1問ごとにコインが見える（+86）。結果画面でまとめて受け取る
   │ 正解するたびに、その国の「なかよし度」+1（5で仲間になる）
   ▼
 冒険ホーム ─┬─ レベルアップ（確実に強くなる）
             └─ 国旗ガチャ（地域を選ぶ。仲間カードを集める近道）
   ▼
 ダンジョン（バトル＝4択。苦手な国がまざる。ボスは自分の苦手な国でできている）
   ├ 勝つ: コイン（初クリアは3倍）、つぎのフロア、ボスを倒すとつぎの地域が開く
   └ 負ける: 「まちがえた国」の一覧 →［この地域を練習する］→ いつものクイズへ
```

- 1回あたりの目安: クイズ1〜2回（2〜5分）→ レベルアップかガチャ → バトル1〜2回（1〜2分）。**スマホで5分あれば1周できる。**
- 長期の目標: 地図喰いを倒す（毎日15分なら約3週間、1日1時間なら約1週間。§5.4）と、195か国を全部仲間にする（1か国につき別々のゲームで5回、のべ975回の正解。国を覚える目標とそのまま同じ）。

## 3. 画面と導線

rpg.js（冒険ホーム）・rpg-cards.js（ガチャ・仲間）・rpg-battle.js（バトル）が `<section id="scr-…" class="wrap" hidden>` を作り、`registerScreen` で登録する。

| 画面 | id | 中身 | PCでの種類（pc_layout 5.10） |
|---|---|---|---|
| 冒険ホーム | `scr-rpg` | 旅人、レベルアップ、つぎにやること、手配書、ダンジョン一覧 | メニュー／一覧 |
| バトル | `scr-battle` | 登場 → 4択 → 勝敗（同じ画面の中で切り替える） | ステージ（高さいっぱい・スクロールなし） |
| 国旗ガチャ | `scr-gacha` | 地域選び・ボタン・提供割合・天井・結果 | ステージ |
| 仲間 | `scr-cards` | 色がついていく世界地図とカード一覧 | 一覧 |

- タブバーは作らない。冒険ホームに［国旗ガチャ］［仲間］のボタンを置き、ほかの画面の左上には「← 冒険」を置く。
- 小さいダイアログ（カードの詳細、引き継ぎコード）は既存の `<dialog id="detail">` を使い回す。

### 3.1 入口（index.html 側の画面）

- **ホーム:** 「プレイ」の次に **「冒険」** ボタンを置く。rpg.js が `#home-play` の後ろに差し込む。並びは プレイ / 冒険 / ランキング / 設定。冒険を一度も開いていなければ、小さく `NEW` を付ける。一番目立つボタンは「プレイ」のまま。
- **トップバー:** `● 1,234` のコインのボタン。`#topbar-extra` があればそこに、なければ `#to-book` の前に入れる。押すと冒険ホームへ行く。
  - 1万以上は `1.2万` のように縮める。399px 以下では `● 1.2万` だけ（文字を足さない）にし、`white-space: nowrap`。360px でブランド・コイン・図鑑・設定が1行におさまることを e2e で確かめる
  - ホームではトップバーが隠れるので、［冒険］ボタンの中に小さく `●1,234` を出す
- **クイズ中:** 進み具合の行の `#ppts` の後ろに `<span id="pcoin" title="コイン（冒険で使える）">+86 <i class="coin"></i></span>` を足す。まだ受け取っていないコインの合計で、描きかえは `requestAnimationFrame` で行う。
  - ドパガキの pt とは別もの。見分けやすいように、コインはいつも金色の丸のアイコン付き、pt は文字だけ
  - 生まれてはじめてコインが出たときだけ、トースト「コインがたまったよ！ 冒険でレベルアップやガチャに使えるよ」
  - 目減りした問題では小さく `×0.5` を添える（なぜ少ないのかがわかるように）。`×0.5` と「はじめて！+20」は `<span class="rpg-pnote">` に入れる
  - スマホ（899px 以下）では同じ行の右はしに置き、冒険の表示が OFF のときより行を増やさない（390×844・360×640 で e2e）。チップの幅は「+9,999 ●」ぶんで固定し、`.rpg-pnote` は行の下のすき間に出す（幅に入れない）。バーの `flex-basis` は 36px、空の `#pscore` は出さない。数や注が変わっても折り返しが変わらないので、タイムアタックの計測中に問題がずれない。PC は1行に収まるので `#ppts` の後ろに並べるだけ
- **結果画面:** `#r-ext` にコインの内訳を書く。`#r-side` があればその中に置く。
  ```
  ● +336 コイン                 いま 1,500
    一発正解 8問 ×10 …… 80
    やり直しで正解 2問 …… 6
    クリアボーナス …… 20
    はじめて正解 5か国 …… 100
  🎁 今日はじめてのクリア +100 ／ 無料ガチャ1回ゲット
  🤝 チリ・ペルーが仲間になった！（5回正解した国は仲間になるよ）
  ✨ 克服！ キリバスはもう苦手じゃない +30
                                      [冒険へ →]
  ```
  - 見出しの数字は、下の行を全部足したもの（ここでは 80+6+20+100+100+30 = 336）。
  - 冒険を開いたことがなくてもコインは貯まる。結果画面がそのまま冒険の入口になる。はじめての画面をまだ見ていない人には、最後の行を「冒険へ →（はじめてなら ●1,000 のお祝いつき）」にする。
- **タイムアタックで失格したとき:** 結果画面に行かないので、トーストで「● +30 コイン」と知らせる。
- **設定:** rpg.js が「冒険（コイン・RPG）を表示する」スイッチを足す（初期値 ON）。OFF にするとボタン・チップ・結果のパネルが消える（コインは裏で貯まり続ける）。勉強だけしたい人のため。
- **直リンク:** `#rpg` で冒険ホームが開く。rpg.js が画面を登録したあとで `location.hash` を見て `show('rpg')` する（index.html の起動処理は変えない）。

  - コインが足りないときは押せない状態にして「あと●40」と出す
  - 下に小さく「上げられるだけ上げる」（`confirm` で「Lv15 まで ●1,230 使う？」と確認する）
  - Lv50 で「MAX」
- **つぎにやること（1行）。** 上から順に判定する:
  1. まだガチャを引いていない、かつコインが1,000以上 →「まずは国旗ガチャ10連で仲間をさがそう（南アメリカがおすすめ）」。押すとガチャ画面へ行き、地域は南アメリカが選ばれた状態で開く
  2. 無料ガチャが残っている →「今日の無料ガチャが引けるよ」
  3. レベルアップでき、かつ Lv が次のフロアの推奨 Lv より低い →「レベルアップできるよ」
  4. 次のフロアがある →「サンゴ礁の海 F3 に挑戦！（推奨Lv9）」。下の目安が「きびしい」なら「ちょっときびしいかも。クイズでコインを稼ごう」を足す
  5. 全部クリアした →「全クリア！ 195か国を仲間にしよう（37/195）」
- **ダンジョンの図版:**
  - 地域の色の帯、ボスの絵文字と名前、推奨 Lv
  - 目安（緑＝余裕 / 黄＝ちょうど / 赤＝きびしい。色と一緒に文字も出す）。Lv だけでなく、おまかせの仲間3枚とがんばりゲージもこみで `hitsNeeded`（倒すのに必要な正解）と `missesAllowed`（まちがえてOK）を計算して決める:
    - 余裕: 通常なら必要な正解4回以下かつミス4回以上OK。ボスなら旗1枚を1回で取れて、ミス4回以上OK
    - ちょうど: 通常なら必要な正解6回以下、ボスなら旗1枚を1回で取れる
    - きびしい: それ以外（ボスで旗1枚に2回以上かかる、など）
  - フロアのチップ ①〜④・👑（クリア済みは塗りつぶし、次に挑むフロアは太い枠、まだ行けないフロアは🔒）
  - 押すと、そのフロアの登場画面へ
- `<details>` **コインのかせぎ方**: §5.1 の例の表と［クイズで稼ぐ］（→ `show('setup')`）
- `<details>` **データ**: 引き継ぎコードをコピー / コードで復元 / 冒険データを消す（2回確認する）

## 4. 旅人（キャラ）とレベル

- ステータスは2つだけ:
  - **HP = 30 + 6×Lv**（何回までミスしていいか）
  - **こうげき = 8 + 2×Lv**（何問で倒せるか）
  - Lv1 で HP36・こうげき10、Lv41 で HP276・こうげき90。DEF、すばやさ、スキル、装備は作らない。
- **強化はレベルアップだけ。** コインを払って Lv を1つ上げる。上限は Lv50。
  - **費用: Lv L → L+1 = 100 + 30×(L−1)** コイン（Lv1→2 が100、Lv10→11 が370、Lv40→41 が1,270、Lv49→50 が1,540）
  - 累計: Lv5 まで 580 / Lv11 まで 2,350 / Lv17 まで 5,200 / Lv23 まで 9,130 / Lv29 まで 14,140 / Lv35 まで 20,230 / **Lv41 まで 27,400** / Lv50 まで 40,180
  - 練習を10問やると（約106コイン）Lv が1つ上がる、という手ごたえから始まる
- **バトルでの値 = 旅人 ＋ 仲間3枚**:
  - こうげき = 旅人のこうげき + round(Σ カードのこうげき)
  - HP = 旅人の HP + round(3 × Σ カードのこうげき)
  - ×（1 + 0.05 × がんばりゲージ）
- **ステータスはセーブしない。** Lv とカードから毎回計算する。だから `TUNING` を変えれば、今までのセーブにもすぐ反映される。
- アバター8種: 🧙 🧝 🦸 🤠 🦊 🐱 🐶 🐧（どれも Emoji 11 以前）。見た目だけで、強さは変わらない。

## 5. 通貨と経済（コイン ●）

画面のコインは CSS で描いた金色の丸（`.coin`）にする。🪙 は Emoji 13 で、古い端末では表示されない。現金とつながる仕組みはどこにもない。

### 5.1 クイズでもらえるコイン

**計算するタイミング:**
- `drill:answer` で1問ごとに計算して、その回のゲームの「受け取り前」（`run`）に足していく。画面の `+86●` はこれを表示する。`run` には、まだ保存していない1問ごとの記録（なかよし度・`mb`・`fe`・`lc`・`wk`・目減りの回数・手配書）もためる。
- `drill:result` で、その回の結果（`outcome`: クリア / 失格 / やめた）にかかわらず受け取る。
- **途中の受け取り:** `pagehide` と `visibilitychange`（`hidden` になったとき。iOS ではアプリの切りかえで `pagehide` が来ないことがある）でも、それまでの1問ごとの分を受け取って保存する。
- **差額だけ払う:** `paid` に「sid → これまでに払った額」を持つ。受け取りは毎回「その回の合計 − 払った額」だけを足し、ためた記録は保存したら `run` から消す。だから何回呼ばれても二重には払わない。bfcache から戻ってゲームを続けたときも、後半のコインとクリアボーナスは結果のときに差額で受け取れる。

**1問ごと（`right === true` のときだけ）**

```
coin = round( base × modeMul × hintMul × weakMul × decay ) + firstEver
```

| 項目 | 値 |
|---|---|
| `base` | 練習・挑戦: そのゲームで初めて出た国を一発で正解（`first`）なら **10**。練習で、まちがえたあとに正解したら **3**（1回のゲームで1か国につき1回まで）。挑戦のやり直し後の正解は **0**（`G.seen` が残っているので `first=false` になる）。タイムアタック: **5** |
| `modeMul` | 国旗→国名 1.0 / 国名→国旗 1.0 / 場所→国旗 1.2 / 国旗→場所 1.2 |
| `hintMul` | 「国名も表示する」が ON（`hint`）なら 0.6 |
| `weakMul` | その国が**苦手**（`weak(a)`: `missesBefore>0` か `wk[a]`。§8）で、`first` で、ヒントなしなら ×2（苦手な国をやっつけると多くもらえる） |
| `decay` | 今日その国でコインをもらった回数（全モード共通、端末の日付で0時に戻る）が 1〜3回目なら 1.0、4〜6回目は 0.5、7回目以降は 0.2 |
| `firstEver` | その国をそのモードで、**クイズで生まれてはじめて**ヒントなしで正解したら **+20**（195か国 × 4モード = 780 枠で、合計 15,600）。払ったかどうかは `fe` のビットで覚える（バトルで立つ `mb` とは別。先にバトルで正解しても、クイズの +20 はなくならない）。画面には「はじめて！+20」と出す。倍率・目減りはかけない |

- 1問で base が1以上なら、最低でも1コイン。不正解は0。
- 知らない `kind` や `mode` は0コインにする（新しいあそび方が増えても、`TUNING` に足すまでは払わない）。
- 挑戦をやめて新しいゲームを始めると `G.seen` が空になるので、また base 10 になる。これは練習で新しく始めるのと同じなので許す（上限は同じ国の目減りが受け持つ）。

**クリアボーナス（`outcome:'clear'` のとき。modeMul と hintMul をかけ、さらに「その回に出た国の目減りの平均」をかけて丸める）**

- 目減りの平均 ＝ その回の国それぞれの `decay`（その回の最初の正解のときの値）の平均。同じ5か国を何度もクリアしてボーナスだけを稼ぐのを防ぐ。ふつうに遊ぶ人はほぼ 1.0 のまま

| あそび方 | ボーナス |
|---|---|
| 練習 | 一発正解が半分以上なら **2×n**。まちがいなし（パーフェクト）なら、さらに **+3×n** |
| 挑戦 | **5×n**。1回目でクリア（ノーミス）なら、さらに **+5×n** |
| タイムアタック | **3×n** |
| タイムアタックの失格（`'fail'`）／やめた（`'quit'`） | ボーナスなし（1問ごとの分は受け取れる） |

- **タイムアタックのずる対策:** クリアで `timeMs < n × 400` なら、その回のコインは全部0（サーバーと同じ基準）。
- **今日はじめてのクリア**（5問以上。タイムアタックの `n×400` で0になった回はふくめない）: **+100** と、**その日の無料ガチャ1回**。
- ドパガキの pt やコンボの倍率は、コインに関係させない。

**例（はじめて正解ボーナスを除く）**

| ゲーム | 時間の目安 | コイン | 1分あたり |
|---|---|---|---|
| 練習・国旗→国名・10問（一発8・やり直し2） | 1.3分 | 80+6+20 = **106** | 約80 |
| 練習・10問・パーフェクト | 1.2分 | 100+20+30 = **150** | 約125 |
| 挑戦・10問・ノーミス | 1.2分 | 100+50+50 = **200** | 約165 |
| 挑戦・10問・3回目でクリア | 2.5分 | 約70+50 = **120** | 約50 |
| タイムアタック・10問・クリア | 0.5分 | 50+30 = **80** | 約160（失格もふくめると約100） |
| タイムアタック・10問・6問目で失格 | 0.3分 | **30** | — |
| 練習・場所→国旗・全世界・全部（195問）・85% | 約25分 | 約1,990+90+470 = **約2,550** | 約100 |

- あそび方による1分あたりの差を約2倍までにおさめた。練習でも、10問で Lv が1つ、または1回引ける。
- 遊びはじめのうちは、はじめて正解ボーナスで1分あたり +60〜+100 くらい上乗せされる。

### 5.4 ペースの見積もり（`tests/unit/rpg-balance.test.mjs` で帯をチェックする）

前提（モデル）: 遊ぶ時間の 3/4 がクイズ（1分に約85コイン＋はじめて正解ボーナス）、1/4 がバトル（1フロア約1.5分）。今日のクリア ●100、手配書 平均 ●120/日、克服 ●90/日（はじめの2週間）。コインの6割をレベル、4割をガチャに使う。仲間3枚のこうげきは、1日目 +5 から増えて4週目に +25（Lv 約12ぶん）まで。推奨 Lv より通常は2、ボスは1低くても勝てるとみなす。はじめて正解ボーナスは主に2モード（390枠）を遊ぶとして計算。

## 6. 仲間カードとガチャ

### 6.1 カード（195枚。countries.js から自動で作るので、手で書くデータはない）

- 1つの国につき1枚。セーブには `cards[iso2] = [★, かさね]` で持つ。
- **カードのこうげき** = `基本値[★] × (1 + 0.2×かさね) × (1 + 0.03×なかよし度) × (地域ボーナス ? 1.5 : 1)`
  - 基本値: ★1 = 1 / ★2 = 3 / ★3 = 6
  - かさね: 0〜4（1つにつき +20%）
  - なかよし度: 0〜10（1つにつき +3%）
  - 地域ボーナス: カードの国の地域とダンジョンの地域が同じなら ×1.5。地図喰いの巣（全世界）では全部のカードにつく
  - カードの HP = こうげき × 3
- 強さの目安:
  - 序盤（★1・なかよし5・地域ボーナスの3枚）→ こうげき +5、HP +15（Lv1 で約+40%）
  - 終盤の標準（★2・かさね2・なかよし10・地域ボーナス）→ 1枚約8、3枚で +25（Lv 12くらいぶん）
  - 最強（★3・かさね4・なかよし10・地域ボーナス）→ 1枚約21、3枚で +63
- **パーティはおまかせ。** バトルの前に、そのダンジョンでのカードのこうげきが高い順に3枚を自動で選ぶ（同じなら ★ が高い順 → 国コード順）。手で組む画面は作らない。

### 6.2 覚えて仲間に（なかよし度）とマスター昇格

- クイズでもバトルでも、**ヒントなしである国に正解したら、その国のなかよし度 +1**（最大10）。1回のゲーム（または1回のバトル）で1か国につき1回まで。持っていない国も数える。だから「5回」は「5回のゲームやバトルで正解」の意味で、画面でもそう書く。
- **なかよし度が5になった国は、持っていなければ★1で仲間になる**（「🤝 チリが仲間になった！」。結果画面に5か国まで並べ、ほかは「ほか3か国」とまとめる）。
- **マスター昇格:** その国を4モード全部で一度はヒントなしで正解していて（`mb` のビットが 1|2|4|8 全部立っている）、なかよし度が10なら、★1 のカードは自動で★2に上がる（「🏅 チリがシルバーに！」）。**★2まではガチャなしで、覚えるだけで届く。**
- ★3（ゴールド）はガチャだけで出る。コレクションのごほうびという位置づけ。

### 6.3 ガチャ

| 項目 | 値 |
|---|---|
| 値段 | 1回 ●100、10回 ●1,000、1日1回の無料（その日はじめてクリアしたあと） |
| 引く地域 | 全世界・6地域から選ぶ。国は**選んだ地域の中から同じ確率**（持っていない国が出やすくなる補正はしない） |
| ★の確率 | ★3 ゴールド **3%** / ★2 シルバー **17%** / ★1 ブロンズ **80%** |
| 10回の保証 | 10枚目は ★3 3% / ★2 97% |
| 天井 | ★3が出ないまま **50回目は★3確定**。カウンターは全部の地域で共通で、保存する。画面に「★3確定まで あと◯回」と出す |
| 天井込みの★3の目安 | 約3.8%（★3 1枚あたり平均約26回 ＝ ●2,600） |

**同じ国が出たとき**

| 状況 | どうなる | ラベル |
|---|---|---|
| まだ持っていない | その★、かさね0で仲間になる | NEW |
| 今のカードより★が高い | ★を上げる（かさねはそのまま） | ランクアップ |
| ★が同じか低くて、かさねが4未満 | かさね+1 | かさね+1 |
| かさねがもう4 | コインを返す（★1 10 / ★2 30 / ★3 100） | おかえし |

```js
// rpg-core.js（乱数は外から渡すので、テストで固定できる）
// region は S.region と同じ形（'all' か '南アメリカ' などの日本語名）。count は 1 か 10 だけ
function pull(st, region, count, rng, C) {
  const T = TUNING.gacha, pool = region === 'all' ? C : C.filter(c => c.r === region), out = [];
  if (!pool.length || (count !== 1 && count !== 10)) return out;
  for (let i = 0; i < count; i++) {
    const r = rng();
    const star = st.pity >= T.pity - 1 ? 3
      : (count === 10 && i === 9) ? (r < T.r3 ? 3 : 2)
      : r < T.r3 ? 3 : r < T.r3 + T.r2 ? 2 : 1;
    st.pity = star === 3 ? 0 : st.pity + 1; st.pulls++;
    const c = pool[Math.floor(rng() * pool.length)];
    out.push({ a: c.a, star, out: addCard(st, c.a, star) }); // 'new' | 'up' | 'stack' | 'refund'
  }
  return out;
}
```

**入れないもの:**
- 期間限定、ピックアップ、カウントダウン
- コンプリートでごほうび（コンプガチャ）
- 引いた回数をほめるバッジ
- 「あと1回で…！」のようなあおり（天井の残り回数をそのまま出すのは除く）

地域の国を全部集めるバッジはあるが、なかよし度だけでも達成できる。

### 7.3 出題（何をどの形式で聞くか）

- **形式:** 国旗→国名（`f2n`）、国名→国旗（`n2f`）、場所→国旗（`m2f`。地図は1枚だけなので、スマホでも軽い）、首都→国名（`cap`。ボスの後半だけ）。国旗→場所（地図4枚）はバトルでは出さない（クイズのほうでやる）。
  - F1〜F2: `f2n` と `n2f` を交互に出す
  - F3〜F4: `f2n` → `n2f` → `m2f` の順にくり返す
  - ボス: `f2n` → `n2f` → `m2f`。旗の残りが半分を切ったら、3問に1問を `cap` にする（「首都が『アピア』の国は？」。選択肢は `makeQuestion(c)` の国名）。首都名と国名が答えのヒントになる国には `cap` を出さない。判定は「同じ」「片方がもう片方をふくむ」「先頭2文字が同じ」のどれか（countries.js で計算すると17か国: アルジェリア、アンドラ、ブラジル、ジブチ、グアテマラ、ギニアビサウ、バチカン、クウェート、ルクセンブルク、メキシコ、モナコ、パナマ、サンマリノ、サントメ・プリンシペ、シンガポール、スリランカ、チュニジア）。単体テストでこの一覧を固定する
  - 地図は `mapSvg` / `zoomableMap` を `{ region: 地域名 }` で描く（全世界は `'all'`）
- **国の袋（通常フロア）:** 次の順に作る。
  1. そのフロアの国（シャッフル）
  2. **さまよう苦手国**を最大2つ。その地域の苦手な国（`weak(a)`。§8）から、misses の多い順 → `wk` が付いている順に選ぶ（「⚠ 前にまちがえた国」の札を付ける）。苦手がなければ、なかよし度の低い国から選ぶ
  3. 手配書の国がこの地域にあれば、それも入れる（「手配中」の札）
  4. 袋が空になったら、そのフロアの国をもう一度、前と別の形式で入れる
  5. まちがえた国は2問あとに、別の形式でもう一度出す
- **ボスの旗:** その地域の国を「misses の多い順 → `wk` あり → なかよし度の低い順 → ランダム」に並べ、上から選ぶ。ただし**苦手国（`weak(a)`）は全体の70%まで（切り捨て）**とし、残りはランダムにする（勝てる見込みを残すため）。だから**ボスは一人ひとり違う「自分専用の復習テスト」**になる。
- 4択は既存の `makeQuestion(c)` で作る（同じ地域の国を優先して選択肢に入れる）。`makeQuestion` は `G` を使わない純粋な関数なので、そのまま呼べる。

### 7.4 バトルのルール

- **時間制限・ターン制限はない。** 速さを競うのはタイムアタックの役目。
- **正解したとき:**
  - 与えるダメージ = `round(こうげき × (1 + 0.1 × min(コンボ, 5)) × (会心 ? 1.5 : 1))`
    - コンボ = この問題の前に何問続けて正解したか
    - 会心は 10% の確率
  - 布がめくれて国旗が見え、「取りもどした旗」の列に入る
  - 「ペルー！ ヤドクガエルに18ダメージ」を出し、**650ms で自動的に次の問題へ**（画面をタップするか Enter で待たずに進める）
- **ボスに正解したとき:** その旗の残りの HP にだけダメージを与える。余ったダメージは次の旗に持ち越さない。旗が残った（推奨 Lv より低い）ときは、同じ国を別の形式でもう1問聞く。だから**ボスを倒すには、ちがう国で N 回の正解が必ず必要。**
- **まちがえたとき:**
  - 敵の攻撃ぶんのダメージを受け、コンボは0に戻る
  - 既存の `misses` に +1、`wk[a]` を付ける（クイズと同じ記録）。正解したときは `misses` を −1（0未満にしない。クイズと同じ）
  - バトルの中の「一発正解（`first`）」は、「このバトルでその国をまだまちがえていない」こと
  - 答え合わせ（`factsHTML(c)` と、地域の地図）を出し、［つぎへ］を押すまで待つ。自動では進めない
- **思い出して復活:** HP が0になったとき、このバトルでまちがえた国（重なりを除いて最大3か国）を、まちがえたときと別の形式で1問ずつ出す。
  - 全問正解なら HP が半分戻って、続きから戦える
  - 復活できるのは1バトルに1回
- **負け:** 「やられた…！ でも、まちがえた国はもう覚えたはず」（バトルの記録は保存する。`misses` だけはその場で書く）
  - がんばり賞のコイン（正解数 × 2、勝ったときの額の半分まで）

  - ［この地域を練習する］: `S.region` をそのダンジョンの `r`（地図喰いの巣なら `'all'`）にし、`store.set('settings', S)`、`P.kind = 'practice'`、`store.set('setup', P)` してから `show('setup')`。rpg.js が `S` と `P` を書きかえるのは**ここだけ**（`misses` はバトルの回答でも書く）
  - ［もう一回］［冒険ホームへ］
- **勝ち:** 「勝利！ ●+36（はじめてのクリア ×3）」→［つぎのフロアへ］［冒険ホームへ］。ボスを初めて倒したら「南アメリカを取りもどした！」と出し、次の地域を開き、［シェア］を出す。

## 8. 苦手を補強するループ（手配書・克服）

- **苦手の判定 `weak(a)`:** 既存の `misses[a] > 0`、**または** RPG の印 `wk[a]` が付いている。
  - なぜ `wk` が要るか: 既存の `misses` は正解で −1 なので、練習で「まちがえる→あとでもう一度出て正解」すると同じゲームの中で0に戻る。`misses` だけでは、練習でまちがえた国が苦手として残らない
  - `wk[a]` は、クイズでもバトルでも、まちがえたら付く。ヒントなしの**一発正解**（`first`）で外れる。同じゲームのやり直しの正解（`first=false`）では外れない
  - 設定の「記録を消す」（`drill:misses-reset`）で `wk` も全部消す
- **克服:** 苦手な国（`weak(a)` が真）に、ヒントなしで一発正解し、その結果 `misses` が0かつ `wk` が外れた瞬間（クイズでもバトルでも）に「✨ 克服！ キリバスはもう苦手じゃない ●+30」。一発正解が条件なので、まちがえたのと同じゲームの中では起きない。1か国につき一生に1回だけ（`ov` に記録する）。`misses` が2以上残っているあいだは克服にならない（あと何回かが「苦手度」として見える）。
- **今日の手配書（3か国）。** その日はじめて `ensureDay()` が呼ばれたときに決める。`ensureDay()` は `drill:start`、バトルの開始、冒険ホームの表示、結果の受け取りの最初に呼ぶ（クイズから先に遊んでも、その日の手配書が数えられる）。
  1. 苦手な国（`weak(a)`）のうち、`misses` がいちばん多い国
  2. なかよし度が1以上で、最後に正解してから7日以上たった国（間をあけた復習）
  3. まだ一度も正解していない国
  - 足りなければ、なかよし度の低い国で埋める
  - クイズでもバトルでも、**ヒントなしの一発正解**で達成（1件 ●30、3件全部でさらに ●100）
  - バトルでは、その国に「手配中」の札が付く
- 連続ログインの日数は数えない。来なかった日に罰はない。

## 9. セーブデータ

- localStorage のキーは **`rpg`**。保存するのは「元になる値」だけ（ステータスや敵の強さは保存しない）。
- 読み書きはすべて `RPG.tx(fn)` を通す。中で localStorage の文字列をその場で読み、`migrate` → `sanitize` → `fn(d)` → `JSON.stringify` して書く。try/catch で包む。

```js
// localStorage['rpg']
{
  v: 1,                  // セーブ形式のバージョン
  intro: false,          // はじめての画面を見て、お祝いをもらったか
  show: true,            // 「冒険を表示する」設定
  coins: 0,              // 持っているコイン（0..1e9 の整数）
  earned: 0,             // これまでに手に入れたコインの合計
  lv: 1,                 // 1..50
  av: 0,                 // アバター 0..7
  cards: {},             // { cl: [2, 1] } = チリ ★2 かさね1
  fr: {},                // なかよし度 { cl: 6 }（0..10、持っていない国もふくむ）
  mb: {},                // モードのビット { cl: 5 }（1 f2n, 2 n2f, 4 m2f, 8 f2m, 16 cap）＝クイズかバトルでヒントなしで正解したことがある（マスター昇格に使う）
  fe: {},                // はじめて正解ボーナスを払ったモードのビット { cl: 1 }（クイズだけ。1 f2n, 2 n2f, 4 m2f, 8 f2m）
  wk: {},                // 苦手の印 { ki: 1 }（§8）
  lc: {},                // 最後に正解した日（通し日数）{ cl: 20387 }
  ov: {},                // 克服のコインを払った国 { ki: 1 }
  floors: {},            // { samerica: 5, oceania: 2 } クリアした最高フロア 0..5
  gauge: {},             // がんばりゲージ { 'oceania:3': 2 } 0..5
  pity: 0, pulls: 0,     // ★3が出ていない回数 0..49、引いた回数の合計
  day: { d: '', n: {}, first: false, free: false },   // 今日の日付、国ごとのコイン回数、今日のクリア済み、無料ガチャ使用済み
  bounty: { d: '', a: [], done: [] },                 // 手配書
  paid: [],              // [[sid, 払った額], …]（最新20件。差額だけ払うため）
  st: { win: 0, lose: 0, flee: 0, revive: 0, combo: 0, nodmg: 0, bossWins: 0, overcome: 0 },
  badgesPaid: []         // コインを払ったバッジの id（二重払い防止）

```

- 大きさは全部そろっても約15KB（`fe`・`wk` をふくむ）。
- **移行:** 次のとおり。`backup` は「壊れたかもしれない元の文字列を `rpg-broken-<時刻>` に写す」（最新3つまで残し、古いものは消す）。
  ```js
  const VERSION = 1;
  const MIGRATE = { /* 1: d => { …; d.v = 2; return d; } */ };
  function migrate(raw) {                       // raw は JSON.parse した値
    if (raw === null || typeof raw !== 'object' || Array.isArray(raw)) return { d: fresh(), readOnly: false, backup: raw != null };
    if (raw.v === undefined) return { d: sanitize({ ...raw, v: 1 }), readOnly: false, backup: true }; // v だけ消えた → v1 とみなして救う
    if (!Number.isInteger(raw.v) || raw.v < 1) return { d: fresh(), readOnly: false, backup: true };
    if (raw.v > VERSION) return { d: sanitize(raw), readOnly: true };   // 新しい版のデータ → 上書きしない
    let d = raw;
    while (d.v < VERSION) {
      const f = MIGRATE[d.v]; if (!f) return { d: fresh(), readOnly: false, backup: true };
      let next; try { next = f(d); } catch { break; }   // 移行が例外を出したら、その版で止めて sanitize に任せる（新しく始めない。次に読むときにもう一度試す）
      if (!next || !Number.isInteger(next.v) || next.v <= d.v) return { d: fresh(), readOnly: false, backup: true };   // v を進めない移行は止まらない
      d = next;
    }
    return { d: sanitize(d), readOnly: false };
  }
  ```
  - `sanitize`（入力が何でも例外を出さない。単体テストで `null`・配列・文字列・巨大な数・`NaN`・`"__proto__"` のキーを入れて確かめる）:
    - `fresh()` の上に重ねる。数値は `Number()` して有限でなければ既定値、整数に丸めて範囲内におさめる（`coins` 0..1e9、`lv` 1..50、`av` 0..7、`pity` 0..49、`fr` 0..10、`floors` 0..5、`gauge` 0..5、`mb` 0..31、`fe` 0..15）
    - オブジェクトのはずの項目が配列や文字列なら `{}`、配列のはずの項目がそうでなければ `[]`
    - 国コードのキーは `byA.has(key)` のものだけ残す（`__proto__` などはここで消える）。新しいオブジェクトは `Object.create(null)` ではなく、残すキーを1つずつ写して作る
    - `cards[a]` は `[★ 1..3, かさね 0..4]` の形でなければ捨てる
    - ダンジョン id と `gauge` のキー（`'<id>:<1..5>'`）は知っているものだけ残す
    - `day.d` が今日でなければ `day` を今日の空のものにする（`day.n` が増え続けない）。`bounty.a` は知っている国コードだけ、3つまで
    - `paid` は `[文字列, 0以上の整数]` の組だけ、最新20件
    - 真偽値は `=== true` のときだけ true（`intro`、`show` は `!== false`）
    - 知らない最上位の項目は残す（新しい版から戻ったときに消さない）
  - **readOnly:** GitHub Pages のキャッシュで、古い rpg.js が新しいセーブを読んだとき。「新しいバージョンのデータが見つかったよ。ページを再読み込みしてね」と冒険ホームとトーストに出し、`RPG.tx` は何も書かない（そのあいだのコインは数えない）。
  - **壊れた JSON:** `store.get` はエラーを飲み込んで既定値を返すので、使わない。localStorage の文字列を直接読み、JSON として読めなければ `rpg-broken-<時刻>` に写してから新しく始め、「データを読めなかったので最初からになったよ」と1回だけ出す。
- **localStorage が使えない・満杯:** `localStorage` に触るだけで例外が出る環境（Cookie を止めた設定など）では、メモリだけで動かし、冒険ホームに「この端末では保存できないみたい。閉じると消えるよ」と出す。`setItem` が `QuotaExceededError` などで失敗したら、トースト「保存できなかった…」を1回だけ出す（クイズは止めない）。
- **既存の `misses` が壊れていても:** RPG が読むときは `const m = (misses && typeof misses === 'object') ? misses : {}` と `Math.max(0, +m[a] || 0)` を通す。
- **タブを2つ開いたとき:** `storage` イベントで `rpg` が変わったら、表示中の画面を描き直す。
- **消えにくくする:** 稼いだコイン（`earned`）が増えた書きこみがはじめて届いたときに `navigator.storage?.persist?.()` を呼ぶ（ページを開くごとに1回まで）。Firefox は確認のダイアログを出すので、起動時の書き直し・日付の書き直し・ゲームの開始・冒険の表示が OFF のときは呼ばない。
- **引き継ぎコード（段階2から入れる）:**
  - 形式は `'CQ1.' + base64url(UTF-8 の JSON)`。中身は `{ rpg: セーブ, m: misses }`（`misses` も一緒に運ぶ。ボスの旗や手配書が苦手の記録を使うため）
  - 復元するときは、前後の空白と改行を消し、`CQ1.` で始まり、長さが 100KB 以下で、base64url と JSON として読めることを確かめる。だめなら「コードが正しくないみたい」と出して何も変えない
  - `migrate` → `sanitize` を通し、「今のデータを上書きする？（Lv12・仲間37 → Lv20・仲間80）」と中身を見せて確認する。`misses` は「まちがえた記録も入れかえる？」を別に確認する（既定は入れかえる）
  - 上書きする前の今のデータは `rpg-broken-<時刻>` と同じやり方で1つ残す
  - iOS Safari の「7日ルール」（使わないと localStorage が消える）と、スマホから PC への引っ越しの保険
- `misses` は index.html の `let` で、設定の「記録を消す」が `misses = {}` で入れかえる。だから**参照をどこかに取っておかない。** 毎回グローバルの `misses` を直接読み書きする（`misses[a] = …; store.set('misses', misses)`）。

## 11. 見た目（絵文字・国旗・CSS だけ）

- **絵文字は Emoji 11（2018年）まで。** 国旗の絵文字は使わない（Windows では「JP」のような文字になる）。国旗はいつも `flag(a)` の SVG にする。コインは CSS の `.coin`（金色の radial-gradient と縁取り）。
- **カードの枠の色**（★は記号でも書くので、色が見分けにくくても区別できる）:
  - `--rpg-b1` ブロンズ #b0793f / `--rpg-b2` シルバー #9aa5ad / `--rpg-b3` ゴールド #d9a520
  - ★3 は枠の上をゆっくり光が流れる（国旗そのものは動かさない。reduced motion のときは止める）
  - カードの裏は方位磁針の模様（`repeating-conic-gradient` ＋ 🧭）
- **地域の色**（図版の帯・バトルの背景にうすく `color-mix`）: 南アメリカ #6fa86a / オセアニア #4fa3c7 / 北中米 #d29a4a / ヨーロッパ #a77bab / アジア #d0705a / アフリカ #c4a02a / 全世界 #5b6b73。ダーク用も用意する。
- **モンスター:**
  - 絵文字を大きく（スマホ `clamp(64px, 18vw, 96px)`、PC は `min(160px, 22cqh)`）、`drop-shadow` を付けてゆらゆら
  - 攻撃が当たると、モンスターが横に揺れて白く光る。倒すと小さくなって消える
  - ボスは丸い「地図帳のスタンプ」の枠に入れ、`BOSS` の札と地域の色の後光を付ける
- **旗ゲージ（ボス）:** 布のかかった小さい旗を N 枚並べ、正解のたびに1枚ずつ本物の国旗に変わる。
- **HP バー:**
  - `role="progressbar"` と `aria-valuenow` を付ける
  - 50% を切ったら黄、25% を切ったら赤（数字も出す）
  - ダメージの数字は小さく浮いて消える（ドパガキ OFF でも出す。手ごたえの基本なので）
- **国旗の扱い:** 揺らさない・欠けさせない・逆さにしない・ダメージの演出に使わない。揺れるのはモンスターと `.bq` の枠だけ。

### 演出と設定

| | ドパガキ OFF（初期設定） | ドパガキ ON |
|---|---|---|
| 正解の攻撃 | モンスターが揺れる・ダメージの数字 | ＋ `FX.sfx('correct', コンボ)`・小さい紙吹雪・コンボ5以上で `FX.pop` |
| まちがい | 旅人の HP が赤く光る | ＋ `FX.sfx('wrong')`・`FX.buzz`・`FX.flash` |

- 音は `FX.sfx` の範囲だけで、呼ぶのはドパガキ ON のときだけ（音の ON/OFF は FX の中で守られる）。
- **reduced motion:**
  - rpg.css のアニメは全部 `@media (prefers-reduced-motion: no-preference)` の中に書く
  - JS でも `matchMedia('(prefers-reduced-motion: reduce)')` を見てから `FX.confetti` / `FX.flash` / `FX.pop` を呼ぶ（FX は自分ではチェックしないため）
  - ガチャのめくり・カウントアップ・浮かぶ数字は省く。自動で次へ進むまでの 650ms はそのまま（動きではないため）
- `S.dopa` は覚えておかず、毎回見る（切り替えたら次の描画から効く）。

## 14. いちばん危ないところと対策

| リスク | 起きること | 対策 |
|---|---|---|
| グローバルの名前がぶつかる | rpg.js 全体が SyntaxError になり、何も言わずに動かない | 即時関数で包む。e2e の最初に「`window.RPG` がある」「ホームに冒険ボタンがある」を確かめる |
| `show()` の SCREENS に、section のない名前を入れる | **アプリの全画面切り替えが壊れる**（イベントの境界でも守れない） | `registerScreen` で section の有無を確かめる。section を先に作る。e2e で全画面を回る |
| タイムアタックの早めの return | 正解のイベントが出ず、タイムアタックの正解がコインや★に数えられない | `drill:answer` は `store.set('misses')` の直後に出す。e2e で「`drill:answer` の数 ＝ 答えた数」を確かめる |
| `drill:result` が出ない・2回出る | コインの払い忘れ・二重払い | `endGame` と `G.ended`。rpg.js 側も `paid`。e2e で練習 / 挑戦のやり直し / タイムアタックのクリア・失格 / やめる / トップバーで離れる のすべてで「ちょうど1回」を確かめる |
| ほかのエージェントと同時に index.html を触る | 同じ行がぶつかる | タイムアタックと PC レイアウトが main に入ってから着手する。フックは目印（「どの行の直後か」）で指定し、行番号は使わない |
| PC で `.qcard` を使う | 2列のグリッドになって狭くなる。id がぶつかる | `.bq` を使う。`qcard` / `next` の id は使わない |

| 苦手国だらけのボス | 苦手な人ほど勝てない | 苦手は70%まで、ミス3回 OK、復活、がんばりゲージ、仲間の地域ボーナス |
