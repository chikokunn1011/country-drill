## 各案の設計

### A1 結果画像のシェア（PR5）

**遊ぶ人から見た動き**
- タイムアタックのクリア画面で、条件の行の下に［結果をシェア］（`btn ghost`）が出ます。
- 今日の難問では、今ある［結果をシェア］（`#dl-share`）を残し、押したときの動きだけを画像つきに変えます。
- 押すと、OS の共有シートに結果の画像（1200×675）と短い文が渡ります。
  - 今日の難問の文は今と同じです（日付・🟩🟥⬜ の帯・結果・`#国旗マスター`）。
- 画像を渡せない端末（`navigator.canShare({files})` が false の端末）や、共有に失敗したときは、X の投稿画面（`twitter.com/intent/tweet`）を新しいタブで開きます。
  - X には文と URL だけを渡します。動きは rpg-cards.js の `share` に合わせます。
  - 保存用の小窓は作りません。
- 共有シートを閉じただけのとき（`AbortError`）は、何もしません。
- 失格（`fail`）と途中でやめたとき（`quit`）は結果画面が出ないので、ボタンもありません。
- 練習と挑戦には、最初の版ではボタンを付けません（決めてほしいこと3）。

**画像の中身**
- **上**: 「国旗マスター」の文字と条件です（結果画面の `cond` と同じ文）。今日の難問は「今日の難問 10/28」にします。
- **まん中**:
  - タイムアタックはタイムを大きく出します（`RANKING.formatTime`）。
  - 今日の難問は「全問正解！ 1:23.4」か「12 / 20 問正解」です。
- **順位**: 画像を作る時点で順位が分かっていれば入れます。間に合わなければ入れず、あとから描き直しません。
  - タイムアタックの順位は `rankOf` の返事を待つので、入らないことが多い見こみです。
- **国旗の列**:
  - タイムアタックは `G.set` の国旗を、横8×縦3の最大24枚まで並べます。それより多いときは、最後のマスを「+N」にします。
  - 今日の難問は国旗を出さず、20マスの帯だけにします。まだ遊んでいない人に答えがばれないようにするためです。
- **下**: `chikokunn1011.github.io/country-drill` と `#国旗マスター`。
- **画像に書かない文字**: 国名と首都は書きません。
- **色**: 描くときに `getComputedStyle(document.body)` で `--bg` `--surface` `--ink` `--muted` `--accent` `--ok` `--ng` `--line` を読みます。ライト・ダーク・ドパガキに自動で合います。JS に色を書かないので、新しい色は増えません。
- **文字**: `document.fonts.load('900 80px "Zen Maru Gothic"')` で読み終えてから描きます。2秒で読めなければ、予備のフォントで描きます。
- **国旗の描き方**（B4 のあとの形）:
  1. `fetch(flag(a))` で SVG を文字として読みます。
  2. `<svg ` を `<svg width="640" height="480" ` に置きかえます（Firefox は大きさの無い SVG を canvas に描けないため）。
  3. Blob URL にして描きます。
  - 同じサイトのファイルなので、canvas は汚れません。
  - `flags/*.svg` のファイル自体には width と height を書きません。書くと `<img>` の大きさが変わってしまうためです。

**しくみ**
- 画像は結果画面を出したときに先に作っておきます。押したときには、もうある File を同期で `navigator.share` に渡します。
  - Safari などは「押した処理の中で share を呼ぶ」ことを求めるためです。
  - 作り終わる前に押されたときは、文だけを今のやり方で共有します。
- 新しいファイル `share-card.js`（`window.SHARECARD`）を作ります。
  - 外から使う口は `SHARECARD.attach(btn, data)` の1つだけです。
  - data の形: `{ kind: 'ta'|'daily', title, big, sub, rank, flags, grid, text }`。国名と首都の項目は持たせません。
  - 中は4つに分けます。
    - `layout(data)`: マスの数と「+N」を決めます。画面に頼らない関数で、unit テストできます。
    - `draw`
    - `toFile`
    - `share`
  - 同じボタンに2回 `attach` したときや、描いている途中で画面を離れたとき（`isConnected` で見る）は、前の処理を捨てます。
- 定数は share-card.js の先頭に1か所だけ置きます: `SHARE = { url: 'https://chikokunn1011.github.io/country-drill/', tag: '#国旗マスター', w: 1200, h: 675, maxFlags: 24 }`。
  - 今日の難問は今 `location.origin + location.pathname` を使っていますが、この定数に変えます。テストのサーバーの URL が出てしまうためです。
- `<script src="share-card.js?v=1">` を daily.js の前に置きます。
  - 読めなかったときは、結果画面にボタンを出しません。今日の難問は今の文だけのシェアのままにします。
- 新しいイベントは作りません。

**置き場所**
- index.html の `showResult()`: タイムアタックのとき、`cond` の下にボタンを足し、`show('result')` のあとで `attach` を呼びます。`#rcard` の中なので、250ms の連打よけがそのまま効きます。
- daily.js の `render()`: `#dl-share` の onclick を `attach` に置きかえます。`bar(r)` は grid から絵文字を作る形にして、決まりを1か所にまとめます。

**データ**
- localStorage のキーは増えません。Supabase も変えません。画像は端末の中で作るだけです。

**#26 との関係**
- プロフィールの名前とかざりは入れません（決めてほしいこと1）。
- さわる場所は、#26 の `#ta-post` `#dl-post` とは別です。

**エラーのとき**
- 画像を作れなかったときは、`console.warn('sharecard', e)` を出して、文だけの共有に切りかえます。
  - この warn は #25 の `adminErrors` には残りません。adminErrors に残るのは、window の error と unhandledrejection だけだからです。
- 国旗1枚の読みこみに失敗したときは、そのマスを `--line` 色の四角にして続けます。

**触るファイル**

### A5 れんぞく日数（PR4）

**遊ぶ人から見た動き**
- B6 の `#home-status` に、1行のかたまりが出ます。例: 「🔥 5日れんぞく（さいこう12日）・お休み券1枚」と、小さな7マス（月〜日）。
  - 7マスは同じ行に小さく収めます。収まらない幅では7マスを隠して、押すと開く小窓で見せます。
- 数える日は、次のどれかを終えた日です。1日に何回遊んでも1日と数えます。
  - クイズ: `drill:result` の `outcome` が `clear` か `fail` のとき。`quit` は数えません。
  - 今日の難問: `drill:daily` の `phase:'end'` で、`outcome` が `clear` か `fail` のとき。
  - 冒険のバトル: `rpg:battle` が出たとき。
  - 道場: `drill:dojo` の `phase:'end'` で `outcome:'clear'` のとき。この1行は A6 の PR で足します。
- 日付は日本時間の0時で切りかえます（`DAILY_CORE.jstDay`）。
- お休み券:
  - 月曜から日曜までの週に1枚あり、自動で使われます。
  - 同じ週に2日休んだときと、8日以上あいたときは、連続が切れます。
- 今日まだ遊んでいないときの表示:
  - きのうまでの連続が続いているときは「今日あそぶと6日に！」と出します。
  - 券でつながる予定のときは「きのうはお休み券でつながるよ」と出します。
  - 切れているときと、はじめての人には「今日あそぶと1日目」と出します。0日でも行は消しません。
- 出題には一切かかわりません。表示だけです。

**置き場所**
- `#home-status` に append します。B6 の称号の札は prepend なので、ぶつかりません。
- `role="group" aria-label="れんぞく日数"` を付けます。ボタンではありません。
- 描き直すのは `drill:screen {name:'home'}` のときだけです。そのたびに localStorage から読み直します。
  - ほかのタブとそろえるための `storage` イベントや `visibilitychange` は使いません。
- 色は今ある `--accent` `--ok` `--muted` `--line` `--surface` だけを使います。
- 高さは、B2 のフッターの行と合わせて、pc_layout の 1366×657 で確かめます。

**データ**
- localStorage のキーは `streak` の1つです（`const KEY = 'streak'`）。
  - 形: `{ v:1, cur, best, last:'YYYY-MM-DD', played:[…], rest:[…] }`。
  - `played` と `rest` は直近14日ぶんだけ残します。
  - 読みこんだら `sanitize` で整えます（`DAILY_CORE.validDay` で日付を確かめ、数は0〜1e5の整数か確かめる）。壊れていたら `fresh()` に戻します。
- badges.js にはさわりません。バッジの記録を移しかえることも、「通算 N日」を出すこともしません。
  - 理由: バッジの日数は今日の難問を数えず、数え方が合わないためです。
- Supabase は変えません。

**計算部分**
- `streak.js` の前半を、DOM にさわらない `globalThis.STREAK_CORE = { fresh, sanitize, record, view, weekOf }` にします。node の vm で読めるようにするためです。
- `record(st, day)`:
  - day が last と同じか、それより前なら何もしません。
  - 空いた日を古い順に見て、その週の券が残っていれば `rest` に入れます。
  - 券の無い日が1日でもあれば、`cur=1` にします。
  - つながったら `cur+1` にします。
- `view(st, today)`: 表示用の値を返すだけで、保存はしません。
- 週は月曜はじまりです。日付の計算は UTC の通算日数で行います。

**#26 との関係**
- `TRANSFER_KEYS` に `'streak'` を足して、引き継ぎで新しい端末に移します。
  - `tests/unit/transfer-keys.test.mjs` は一覧を deepEqual で比べているので、期待する一覧にも足します。
  - index.html の `profile.js?v=` を上げます。

**エラーのとき**
- `store`・`emit`・`$`・`DAILY_CORE` が足りないときは、`console.error` を出して、行を出しません。
- イベントを受け取る関数は try/catch で囲み、クイズや冒険の進み方を止めません。
- 端末の時計が戻ったときは、何もしません。

**触るファイル**
- `streak.js`（新規）、`streak.css`（新規）
- `index.html`（link と script の2行、`profile.js?v=`）
- `profile.js`
- `tests/unit/transfer-keys.test.mjs`
- `docs/events.md`（受け取る側と読み込みの順番。新しいイベントは無し）
- `tests/unit/streak.test.mjs`（新規）、`tests/e2e/streak.test.mjs`（新規）

3. カードを押すと始まります。1回は10問（`ROUND`）です。
   - 選択肢は同じグループの国だけで、最大4つです。2〜3か国のグループは2択か3択になります。

   - 正解したとき: 正解の国旗と、まちがえやすい相手の国旗を並べます。

7. 終わったら道場の画面に戻り、結果を1行出します。結果画面とランキングは使いません。

### B5 埋めこみ「今日の国旗」（PR9・後回し）
