# 国旗クエスト 仲間の編成・チームボーナス・バトル中の仲間・プロフィールのかざり 設計書

2026-10-27 / スレッド「国旗マスターの新機能アイデアを考える」でチコと決めた内容。

## 0. まとめ

チコの声:「国を仲間にする要素、遊んでみたがあまりメリットを感じない」。

原因: 仲間は「こうげきの数値」だけで、バトル前に強い順の3枚が自動で選ばれる（`rpg-core.js` の `party()`）。どの国も中身が同じで、スマホのバトル画面には仲間が出ていない。

やること（チコが選んだ A・B・E ＋ プロフィール）:

| | 内容 |
|---|---|
| A 編成 | 仲間3枚の編成を自分で組める。最初は1枠、ゲーム内コインで買い足して最大5枠 |
| B チームボーナス | 同じグループ（13グループ）の仲間が2枚で＋10%、3枚で＋25%（こうげき・HP） |
| E バトル中の仲間 | スマホでも仲間3枚を出す。正解したとき仲間カードが跳ねて「◯◯の援護！」 |
| プロフィールのかざり | 旅人カードに好きな仲間の国旗を3つまで飾る。冒険ランキングにも出る |

**守ること（今の RPG 設計書 2026-10-26-rpg-design.md の約束のまま）**
- 本物のお金は使わない。枠の購入はゲーム内コイン（●）だけ
- 国旗は揺らさない・破らない・逆さにしない。動くのはカードの枠だけ
- 出題は国旗・国名・場所だけ（首都は出題しない）
- 一度も編成を組んでいない人の強さは今と同じ（強い順の3枚）

## 1. ルール

### 1.1 編成（A）

- **枠:** 最初は1枠（「編成1」）。枠の数は1〜5。
- **枠の値段（コイン）:** 2枠目 ●2,000 / 3枠目 ●3,000 / 4枠目 ●4,000 / 5枠目 ●5,000（合計 ●14,000）。`TUNING.team.slotCost = [2000, 3000, 4000, 5000]`。
  - コインが足りないときはボタンを押せない状態にして「あと●◯◯」と出す。
  - 買う前に `confirm`「●2,000 で編成の枠を1つ増やす？」。買ったら戻せない。
- **中身:** 1枠に仲間を0〜3枚。同じ国は1枠に1回まで。別の枠どうしでは同じ国を使ってよい。
- **まだ組んでいない枠:** 枠の中身が `null`（古いセーブ・新しく買った枠）のときは、今と同じく、そのダンジョンでのカードのこうげきが高い順に3枚で戦う（`party()`。チームボーナスはつけない）。編成画面ではその3枚を見せて「まだ組んでないよ（強い順の3枚で戦う）」と出す。
  - 枠に1枚でも入れたり外したりしたら、その枠は配列（ふつうの編成）になる。画面から `null` に戻す手段は無い（2026-10-27 チコ決定）。
- **［おまかせ］ボタン（1つだけ）:** 今選んでいるダンジョンで強い順の3枚（`party()` と同じ並び: 地域ボーナスこみのこうげき → ★ → 国コード）を、その枠にふつうの編成（`c` = 配列）として入れる。チームボーナスは考えずに選ぶ。
  - 入れたあとはふつうの編成なので、たまたま同じグループがそろえばチームボーナスがつく（そこから入れ替えられる）。
  - 強い順の3枚はチームボーナスを狙わないので、自分で組むと強くできる余地が残る（これが「選ぶ理由」）。
- **名前:** 1〜8文字（前後の空白を除く）。空なら「編成N」に戻す。表示は必ず `esc()`。
- **使う枠:** 最後に選んだ枠を1つ覚える（`tsel`）。全部のダンジョンで共通。
- 配列の枠が0枚のときは、仲間なしで戦う（強い順の3枚にはしない）。

### 1.2 チームボーナス（B）

- **グループ（13）:** プレイの細かい10地域（index.html の `SUBREGIONS`）に、細かく分けていない残りの3つを足す。195か国はどれか1つにだけ入る。

| グループ | 中身 |
|---|---|
| 東アジア・東南アジア・南アジア・中央アジア・西アジア | `SUBREGIONS` と同じ |
| 東ヨーロッパ・西ヨーロッパ | `SUBREGIONS` と同じ |
| カリブ海 | `SUBREGIONS` と同じ |
| アフリカ北側・アフリカ南側 | `SUBREGIONS` と同じ |
| 南アメリカ | `r === '南アメリカ'` の全部 |
| オセアニア | `r === 'オセアニア'` の全部 |
| 北・中央アメリカ | `r === '北・中央アメリカ'` のうちカリブ海以外 |

- `rpg-core.js` は index.html を読めないので、グループの表を `rpg-core.js` に持つ（`GROUPS`）。**index.html の `SUBREGIONS` と中身が同じことを単体テストで確かめる**（index.html を文字列で読んで比べる）。全195か国がちょうど1グループに入っていることもテストする。
- **ボーナス:** 編成の3枚のうち、同じグループの枚数がいちばん多いグループで決める。
  - 2枚 → ＋10%、3枚 → ＋25%（`TUNING.team.bonus = [0, 0, 0.10, 0.25]`）
  - 1枚だけのグループばかりなら 0
- **かけ方:** バトルのこうげき・HP の両方に、がんばりゲージと掛け算で重ねる。
  ```
  こうげき = round((旅人 + round(Σ カード)) × (1 + 0.05×ゲージ) × (1 + チーム))
  HP       = round((旅人 + round(3 × Σ カード)) × (1 + 0.05×ゲージ) × (1 + チーム))
  ```
- ダンジョンの地域ボーナス（カードの国がダンジョンの地域なら ×1.5）は今のまま。両方そろうこともある（例: アジアのダンジョンに東南アジア3枚）。
- まだ組んでいない枠（`c === null`）にはチームボーナスをつけない（今遊んでいる人の強さを変えないため。2026-10-27 チコ決定）。ボーナスは配列の枠だけ（［おまかせ］で入れた枠もふくむ）。

### 1.3 プロフィールのかざり

- 持っている仲間から0〜3か国を選ぶ。順番は選んだ順。編成とは関係ない（弱いカードでもよい）。
- 冒険ホームの旅人カードと、冒険ランキングの名前の横に、小さい国旗で出す。
- サーバーは RPG のデータを持たないので「本当に持っているか」は確かめられない。見た目だけの機能として割り切る（国コードが195か国のどれかで、3つ以内で、重なりが無いことだけ確かめる）。

## 2. セーブデータ（localStorage `rpg`、v は 1 のまま）

最上位に3つ足す。**バージョンは上げない。** 今の `sanitize` は「知らない最上位の項目は残す」ので、キャッシュに残った古い rpg.js が読んでも消えない（v を上げると古い rpg.js が readOnly になってしまう）。

```js
teams: [{ n: '編成1', c: null }],   // 1..5 個。c は null（まだ組んでいない＝強い順の3枚）か 国コードの配列（0..3、重なり無し）
tsel: 0,                            // 使う枠の番号 0..teams.length-1
deco: [],                           // かざり 国コードの配列（0..3、重なり無し）
```

- `fresh()` に上の既定値を足す。
- `sanitize`:
  - `teams` が配列でなければ既定値。5個を超えたら先頭5個。0個なら既定値。
  - 各要素: `n` は文字列を前後の空白を除いて8文字まで、空なら `'編成' + (i+1)`。`c` は `null` か、`byA.has()` の国コードだけを重なり無しで3つまで残した配列。それ以外の形なら `null`。
  - `tsel` は整数に丸めて 0..teams.length-1。
  - `deco` は `byA.has()` の国コードを重なり無しで3つまで。
  - 持っていない国（`cards` に無い国）は sanitize では消さない（引き継ぎコードの復元の順番などで一時的に食い違っても消えないように）。**使うときに**持っている国だけにしぼる。
- 引き継ぎコードは今のまま（セーブ全体を運ぶので、編成とかざりも一緒に運ばれる）。

## 3. 計算（rpg-core.js）

- `GROUPS`（§1.2 の表）と `groupOf(a)`。
- `teamBonus(list)`: 国コードの配列 → 0 / 0.10 / 0.25 と、そのグループ名（画面に出す用）。
- `party(d, id)` は今のまま（強い順の3枚。`c === null` の枠と［おまかせ］ボタンが使う）。名前も中身も変えない（今のテストと rpg-balance のペースの見積もりがそのまま使える）。
- 新しく `teamParty(d, id, t = d.tsel)`: 枠 t の中身が `null` なら `party(d, id)`、配列なら持っている国だけにしぼり、`party()` と同じ形 `{ a, atk }` で返す（atk は地域ボーナスこみ）。
- `battleStats(d, id, floor, t = d.tsel)` は `teamParty` を使い、§1.2 の式でチームボーナスをかける。返り値に `team: { bonus, group, slot: t }` を足す。
- 冒険ホームのダンジョンの目安（余裕／ちょうど／きびしい）も `battleStats` を通るので、使う枠の強さで出る。
- 枠の購入 `buySlot(d)`: 枠が5未満で、コインが値段以上なら、コインを引いて `{ n: '編成N', c: null }` を足し、`tsel` を新しい枠にする。できたら true。
- どれもテストできる純粋な関数（セーブ `d` を受け取って書きかえるだけ。書き込みは rpg.js の `RPG.tx`）。

## 4. 画面

### 4.1 編成画面（新しい画面 `#scr-team`、新しいファイル `rpg-team.js`）

入口: 冒険ホームの［🗂 仲間］の隣に［⚔️ 編成］。バトルの登場画面の［へんせい］からも来られる（そのときは「← バトルにもどる」で登場画面に戻る）。

```
┌──────────────────────────────┐
│ ← 冒険        編成               │
│ [編成1][編成2][🔒●3,000][🔒][🔒] │ ← 枠のタブ
│ 編成1 ✏️  まだ組んでないよ（強い順の3枚で戦う）│
│ ┌────┐┌────┐┌ ─ ─┐               │
│ │旗 ★2││旗 ★1││ 空き │            │
│ └────┘└────┘└ ─ ─┘               │
│ ダンジョン: [アジア ▼]            │
│ ⚔️ 62  ❤️ 210  チーム 東南アジア×2 ＋10% │
│ [        おまかせ        ]        │
├──────────────────────────────┤
│ 仲間 37/195  [全部][アジア]…      │ ← 地域のチップで絞る
│ [カード][カード][カード]…         │ ← 入っている国には ✓
└──────────────────────────────┘
```

- 枠のタブ: 買った枠は名前、まだの枠は🔒と値段（次に買える1つだけ押せる。その先は🔒だけ）。タブを押すとその枠を選ぶ（`tsel` も変わる）。
- ✏️ で名前の入力欄に変わる（Enter／欄の外で確定、Esc で取り消し）。
- 3枠: カードをタップで外す。空きは点線。
- 仲間の一覧: 今の仲間画面と同じカードの見た目（`RPG.cardHTML`）。タップで空いている枠の先頭に入る。もう入っている国は外す。3枚埋まっているときは「入れ替えたいカードを先に外してね」とトースト。
- 一覧の並び: そのダンジョンでのこうげきが高い順（同じなら★ → 国コード）。カードにグループ名を小さく出す（チームを組む手がかり）。
- ダンジョンの選択: 強さとチームボーナスを見るためだけ（保存しない）。最初は「次に挑むダンジョン」。
- PC（900px〜）: 左に枠と強さ（sticky）、右に仲間の一覧。
- 仲間が0枚のとき: 「仲間がいると強くなるよ（国旗ガチャ・5回正解）」と、ガチャへのボタン。

### 4.2 バトルの登場画面

今の「自動で選ばれた仲間3枚」の場所を次にする:

```
編成  ◀ 編成2 ▶            ［へんせい］
[旗★2][旗★1][旗★3]  地域ボーナス ×1.5
チーム 東南アジア×3 ＋25%
倒すのに必要な正解: 約4回 ／ まちがえてOK: 4回まで
```

- ◀▶ で枠を切り替えると `tsel` が変わり、強さ・必要な正解の数・ミスOKの回数がその場で描き直される。枠が1つのときは ◀▶ を出さない。
- キーボード: ←→ で枠の切り替え（登場画面のときだけ）。Enter は今どおり［たたかう］。
- ［へんせい］: 編成画面へ。戻ると同じフロアの登場画面を作り直す。

### 4.3 バトル中の仲間（E）

- **スマホ:** 旅人の HP の行の下に、仲間3枚を1行（国旗＋★の小さいカード、高さ約36px）。短い画面（`max-height: 700px`）では国旗だけに縮め、sticky の高さを今より増やさない（360×640 で4つ目の選択肢が画面に入る e2e を今のまま通す）。
- **PC:** 今の仲間3枚の表示を少し大きくする（国旗の幅 48px → 64px くらい）。
- **正解したとき:** 仲間カードが左から順に 80ms ずつずらして、上に 6px 跳ねる（`transform: translateY` をカードの枠にかける。国旗は枠の中で一緒に動くだけで、回したり揺らしたりしない）。ログに「チリ・ペルー・タイの援護！ ヤドクガエルに18ダメージ」。仲間0枚なら今の文のまま。
- **動きを抑える設定（`prefers-reduced-motion: reduce`）:** 跳ねずに枠が一瞬光るだけ。
- チームボーナスがついているときは、仲間の列の端に「＋25%」の小さい札。

### 4.4 冒険ホームの旅人カード（プロフィールのかざり）

- 名前の行の横に、かざりの国旗を3つ（小さく）。空きは点線の小さい四角。
- かざりを押すと選ぶ画面（`<dialog>`）: 持っている仲間の一覧から最大3か国。もう一度押すと外れる。［決定］で保存。
- 仲間が0枚のときは、かざりの欄を出さない。

## 5. 冒険ランキング

### 5.1 サーバー（supabase/schema.sql に足す。drop を使わない）

```sql
alter table rpg_players add column if not exists deco text[] not null default '{}';
alter table rpg_players add column if not exists deco_at timestamptz;

-- 195か国の国コード（countries.js と同じ。単体テストで一致を確かめる）
create or replace function rpg_codes() returns text[] language sql immutable ... as $$ select array['af','al',…] $$;

-- かざりを変える（3つまで・重なり無し・rpg_codes() のどれか）。10秒以内の連投は断る（deco_at で数える。rpg_update とは別）
create or replace function rpg_set_deco(p_token text, p_deco text[]) returns jsonb ...;

-- ランキング（かざりつき）。top_rpg は返す列の形を変えると drop が要るので、新しい名前で作る。古い top_rpg は残す（キャッシュの古い rpg-rank.js 用）
create or replace function top_rpg2(p_sort text)
returns table(nickname text, lv int, dungeons int, floors int, deco text[], created_at timestamptz) ...;
```

- 返す `reason`: `bad_token` / `bad_deco` / `not_found` / `too_soon`（今の関数と同じ言葉）。
- `rpg_register` / `rpg_update` / `rpg_rename` / `rpg_unregister` は変えない。
- 権限は今と同じ形（`revoke all … from public; grant execute … to anon;`）。
- テストは `tests/sql/run.sh`（ローカル PG16）に足す: 正しい3つ・4つ・重なり・知らないコード・空配列・10秒以内・消された行。
- **本番 DB への適用は、PR を見てもらうときにチコの明示 OK をもらってから**（Supabase MCP の `apply_migration`、名前 `rpg_deco`）。

### 5.2 画面（rpg-rank.js・ranking.js）

- `ranking.js` に `rpgSetDeco({ token, deco })` と、`topRpg` を `top_rpg2` に向ける（`top_rpg2` が無い＝404 のときは `top_rpg` にもどす。DB 適用前でも壊れない）。
- 自動更新: 今の `scheduleAuto` に「送ったかざり（`sent.deco`）と今のかざりがちがう」も足す。かざりは `rpgSetDeco`、記録は今の `rpgUpdate` で、別々に送る（どちらも GAP をあける）。登録していなければ送らない。
- 一覧の行: 名前の後ろに国旗を3つまで（高さ 1em くらい、`flag(a)`）。知らない国コードは出さない。自分の行も同じ。

## 7. テスト

- **rpg-balance:** 変えない（強い順の3枚のまま）。通ることを確かめる。
- **SQL:** §5.1。
- **e2e（tests/e2e/ に rpg_team.test.mjs）:** 編成画面で入れて外す／枠を買う（コイン不足で押せない）／名前を変える／登場画面で◀▶して強さが変わる／正解で援護のログ／スマホ 360×640 で4つ目の選択肢が画面に入る／かざりを選ぶと冒険ホームに出る／ランキングの行に国旗（Supabase は今の e2e と同じく route で差し替え）。

## 8. やらないこと

- 枠ごとの装備・スキル・役わり（D 案）、助っ人（C 案）
- ダンジョンごとに編成を自動で切り替えること（使う枠は1つを覚えるだけ）
- ランキングに編成やチームボーナスを出すこと
- サーバーでかざりの国を持っているか確かめること
