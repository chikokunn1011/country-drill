# 今日の難問（毎日1回のチャレンジ＋その日のランキング）設計書

- 日付: 2026-10-28
- 対象: 国旗マスター（https://chikokunn1011.github.io/country-drill/）
- 状態: 2026-10-28 チコ決定「問題は20問、それ以外はおすすめ」

## 1. 目的

毎日1回だけ挑戦できる難しい問題を用意し、その日の問題だけのランキングを作る。毎日サイトに来る理由を作る。

チコの要望（2026-10-28）:
- 毎日1回挑戦できる問題。問題は難しい
- 途中で間違えたらそこで終了。その時点の正答数がランキングに載る
- 全部正解なら「全問正解」とタイムが載る

決まっていること（プロジェクトの方針）:
- 出題は国旗・国名・場所だけ（首都は問わない。答えのあとに表示するのはOK）
- 「毎日」は日本時間0時で切り替え
- 全員同じ問題（日付から決まる）
- 1日1回は端末ごと（localStorage）。サーバー側でも同じ名前は1日1回まで

## 2. 遊ぶ側の流れ

1. ホームのプレイの上に「📅 今日の難問 10/28」の細い帯（メニューのボタンの並びは変えない）。挑戦前なら「NEW」、挑戦後は「挑戦ずみ」。
2. 今日の難問の画面（`daily`）:
   - 挑戦前: 日付（例 10月28日）、ルール（20問・1ミスで終了・タイムも計る）、「挑戦する」ボタン、今日のランキングをのぞくボタン。
   - 挑戦後: 今日の結果、今日の問題と答え（まだ挑戦していない人に広まらないよう、自分がとどいた問題まで）、ランキング（今日／昨日タブ）、「次の問題まで あと◯時間◯分」。昨日のタブでは昨日の20問の答えを全部出す。
   - 別のタブで挑戦中なら「いま別のタブで挑戦中」とだけ出す（そのタブの記録を止めない）。
3. 「挑戦する」を押すと、その時点で「今日は挑戦ずみ」を保存（リロードでのやり直し防止）。
4. クイズ中: 上に `3 / 20`、経過タイム、「むずかしさ ★★」。正解ならすぐ次へ（タイムアタックと同じ）。1問目を出した瞬間から計測。
5. 間違えたら終了: 正解を表示して、「ここまで◯問正解」。全部正解なら「全問正解！タイム ◯◯秒」。
6. 結果: ニックネーム（前回の名前を自動入力）で「ランキングに載せる」。載せるかは本人が選ぶ。送ると「今日◯位」。
7. 途中でやめた（画面を離れた・閉じた）ら、その時点までの正答数で終了扱い。結果画面を出してランキングに載せられる。閉じた場合は次に開いたとき「前回の結果」を出して載せられる。
9. シェア: 結果をシェアするボタン（「国旗マスター 今日の難問 10/28 全問正解 32.15秒 #国旗マスター」、□■の並びでどこまで正解したか）。

## 3. 問題の作り方（全員同じ）

- その日の文字列 `YYYY-MM-DD`（日本時間）から乱数の種を作り、決まった乱数（mulberry32）だけで出題・選択肢・並びを決める。`Math.random` は使わない。
- 形式（チコ決定）: 1問ずつ4形式（国旗→国名・国名→国旗・場所→国旗・国旗→場所）から乱数で選ぶ。同じ形式は3回まで続かない。
- 問題数（チコ決定）: 20問。
- 難しさ（チコ決定）: 3段階。
  - 1〜6問目: 「なじみの薄い国」（よく知られた約50か国を除いた国）から。選択肢は同じ地域から。
  - 7〜14問目: 「似た国旗グループ」（手で作る表。例: チャド・ルーマニア・アンドラ・モルドバ／インドネシア・モナコ・ポーランド／アイルランド・コートジボワール・イタリア／オランダ・ルクセンブルク／ニュージーランド・オーストラリア…）から出し、選択肢を同じグループでそろえる（足りない分は似た色の国旗の国）。
  - 15〜20問目: 小さい国（面積25,000km²未満）でなじみの薄い国から。選択肢は、その国が似た国旗グループにいればグループの国、そうでなければ同じ地域の小さい国（場所系では小国の丸印が近い国どうしになる）。
- 同じ国は同じ日に2回出ない。似た国旗のグループも1日1回まで。
- 出題の組み立ては `daily-core.js`（画面を持たない純粋な関数）にまとめて単体テストする。データや規則を変えると問題が変わるので、変更は日付の切り替わりに合わせる必要はないが、その日の途中で変えると「ランキングの問題」と「新しい問題」がずれる。`VERSION` を問題の種に含め、変えたときだけ翌日から新しい規則にする（`since` の日付）。

## 4. ランキング

並び順:
1. 全問正解の人がいちばん上。タイムが短い順。
2. その下に、途中で終わった人。正答数が多い順、同じならタイムが短い順（その時点までのタイム）。
3. 同じ記録なら先に載せた人が上。

見せ方（チコ決定）: 「今日」「昨日」の2タブ、上位50件。行は 順位・ニックネーム・「全問正解」または「◯問」・タイム。昨日のタブの下に「昨日の問題と答え」。

今日の難問のランキングは今日の難問の画面の中だけに出す（ホームの「ランキング」画面には足さない）。

## 5. サーバー（Supabase）

テーブル `daily_scores`（RLS ON・ポリシー無し、関数からだけ使う）:

| 列 | 型 | 内容 |
|---|---|---|
| id | bigint | 自動 |
| day | date | 日本時間の日付 |
| nickname | text | 1〜12文字 |
| correct | int | 正答数（0〜問題数） |
| total | int | 問題数 |
| time_ms | int | 全問正解ならクリアタイム、途中終了ならそこまでのタイム |
| created_at | timestamptz | |

一意: (day, NFKC＋小文字にした nickname)。同じ日に同じ名前は1回だけ（2回目は `name_taken`。全角半角・大文字小文字のちがいも同じ名前）。返事が届かず送り直して `name_taken` になったときは、同じ名前・同じ記録の行があれば載せたことにする。

関数（security definer、anon 実行可）:
- `submit_daily(p_day text, p_nickname text, p_correct int, p_total int, p_time_ms int)` → `{ok, rank}` か `{ok:false, reason}`
  - p_day は日本時間の今日。日付をまたいで遊んだ人のために、0時から30分間は昨日も受け付ける。それ以外は `bad_day`。
  - p_total は決まった問題数（20）。p_correct は 0〜p_total。
  - タイムは 正答数×400ms 以上・3時間以下（タイムアタックと同じ考え方）。
  - 名前は 1〜12文字・NGワード（タイムアタックと同じ `ng_words()`）。
- `top_daily(p_day text)` → 上位50件（nickname, correct, total, time_ms, created_at）
- `daily_rank_of(p_day text, p_correct int, p_time_ms int)` → 何位相当か

`supabase/schema.sql` に追記。drop を含まない形にして MCP の apply_migration で本番に入れる（チコの明示OKのあと）。

## 6. ファイル

- `daily-core.js`（新規）: 日付・乱数・出題の組み立て・似た国旗の表・ランキングの並べ方。ブラウザでは `window.DAILY_CORE`、テストでは vm で読む。
- `daily.js`（新規）: 画面（`registerScreen('daily', …)`）、クイズ、結果、ランキング、シェア。index.html の関数（flag・mapSvg・zoomableMap・factsHTML・show・store・SND など）を使う。足りないときは何もしない（rpg.js と同じ起動チェック）。
- `ranking.js`: `dailySubmit` / `dailyTop` / `dailyRankOf` を追加。
- `index.html`: ホームのボタン、`<section id="scr-daily">`、スクリプトの読み込み。
- `supabase/schema.sql`、`tests/sql/test_schema.sql`、`tests/unit/daily-core.test.mjs`、`tests/e2e/daily.test.mjs`。

## 7. ほかの機能とのつながり

- 今日の難問は `drill:result` / `drill:answer` を出さない（バッジ・苦手・冒険コインの計算に混ぜない。kind が違う遊び方を badges.js が知らないため）。代わりに `drill:daily` を出しておく（あとでバッジを足すとき用）。
- 苦手（misses）は増やさない。

## 8. テスト

- 単体: 同じ日付なら同じ問題・違う日付なら違う問題、20問・重複なし・首都が出ない、選択肢4つで正解が1つ、似た国旗の段階で選択肢がグループから出る、日本時間の日付の切り替え（23:59 / 0:00）、ランキングの並べ方。
- SQL: 受け付ける／はじく（日付・名前・正答数・タイム・同名）、並び順、0時から30分の昨日受け付け。
- e2e: 挑戦→途中で間違えて終了→載せる（fetch はスタブ）、全問正解→タイム、リロードしても再挑戦できない、日付が変わると挑戦できる。

## 9. 範囲外

- ログイン、端末をまたいだ1日1回の制限（同じ人が別の端末や別の名前で遊ぶのは防げない）。
- 過去の日の問題の練習（あとで足せる）。
