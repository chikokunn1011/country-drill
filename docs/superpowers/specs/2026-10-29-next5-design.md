## F1 白地図タップの直し

### 1. スマホでズームボタンが国を隠す

- 今: 出題地図の右下に ＋・−・全体 のボタンが地図の上に重なっている。幅390pxだとオーストラリアあたりが隠れて押せない。
- 直し方: **白地図タップの地図だけ**、幅600px未満のときにボタンを地図の外（地図のすぐ下、右寄せの1行）に出す。
  - ほかのモードの地図は「色の付いた国を見る」だけなので、重なっても答えに困らない。今のままにする（レイアウトのテストを動かさないため）。
  - PC（900px以上）は今のまま地図の上。
- テスト: 390px で、ボタンの四角と地図の svg の四角が重ならないこと。

### 2. キーボードで答えられない

- 今: ほかのモードは 1〜4 キーで答えられるが、白地図タップはマウス・指でしか答えられない。
- 直し方: 地図にフォーカスが入ると、**地図のまん中に照準（＋の印）** を出す。
  - 矢印キー: 地図を動かす（照準は真ん中のまま、地図がずれる）。Shift＋矢印で大きく動く。
  - `+` / `-`: ズーム。`0`: 全体。
  - `Enter` / `Space`: 照準の場所をタップしたのと同じに答える（tapJudge をそのまま使う）。
  - 問題が出たら地図に自動でフォーカス（PC のみ。スマホは画面キーボードが出ないよう何もしない）。
- 下のヒントの文を「矢印キーで動かして Enter で答える」に変える（キーボードのある PC だけ）。
- スクリーンリーダー向けに、地図に `aria-label="白地図。矢印キーで動かし、Enter で真ん中の場所を答える"` を付ける。

## D2 アプリ化（PWA）

### しくみ

- `sw.js`（service worker）をサイトの根に置き、index.html などから登録する。範囲は `/country-drill/` 全体。
- **ページ（HTML）**: ネット優先。つながらないときだけ保存したものを出す。→ 更新はいつも今までどおりすぐ届く。
- **`?v=` 付きの js・css**: キャッシュ優先。`?v=` が上がれば別の URL なので、新しいものを取りに行く。
- **`?v=` の無いもの（flags/*.svg・vendor・world.js・textures・icons）**: キャッシュを出しつつ裏で新しいものを取る（stale-while-revalidate）。
- **Supabase（ランキング・プロフィール）・Google Fonts・Google フォーム**: さわらない（いつもネット）。つながらないときは今あるエラー表示のまま。
- **最初に入れておくもの（precache）**: index.html・index.html が読む js/css（`?v=` 付きのまま）・world.js・vendor・アイコン・国旗195枚（約2MB）。合わせて約5MB。
  - 国旗を全部先に入れる理由: オフラインで「全世界」を選ぶと、どの国旗も要るから。
  - 国のページ・まとめページは先に入れない（見たものだけ残る）。
- **一覧の作り方**: `tools/make_sw.mjs` が index.html から読みこむファイルと `?v=` を拾い、`sw.js` の一覧と版の番号（中身のハッシュ）を書きかえる。手で書かない。
  - テスト `sw.test.mjs`: 「今の sw.js が make_sw.mjs の出力と同じ」こと。ファイルを足したのに作り直し忘れたら落ちる。
- **古いキャッシュの片づけ**: 版が変わったら、新しい sw が入ったときに古い版のキャッシュを消す。
- **ページを開いている途中で新しい版が入ったとき**: 何もしない（次に開いたときから新しい版）。いま遊んでいる途中で画面が変わらないように。

### 「アプリとして追加」の案内

- **Android・PC の Chrome / Edge**: ブラウザが「追加できる」と知らせてきたら（beforeinstallprompt）、ホームのアイコン列の下に1行の帯を出す。
  - 「ホーム画面に追加すると、電波がなくても遊べる ［追加する］ ×」
- **iPhone・iPad の Safari**: 自動では追加できないので、同じ帯の［追加する］で手順の小窓（共有ボタン → 「ホーム画面に追加」）を出す。
- **出す条件**: 2日目以降に来た人だけ（初めての人には出さない）。× で消したら30日出さない。もうアプリとして開いているときは出さない。
- **設定**にも同じ［アプリとして追加］を置く（帯を消した人用）。

### その他

- manifest の `start_url` は今のまま `./`。
- プライバシーポリシーに1行足す: 「すばやく開いたりオフラインで遊べるように、サイトのファイルを端末に保存します（個人の情報は含みません）」。
- 管理用サイト（admin.html）は precache しない。ページなのでネット優先の扱いになり、困らない。

### テスト

- オフラインにして（Playwright の `context.setOffline(true)`）、ホーム → 全世界・国旗→国名 で10問遊べる。
- `?v=` を上げた js が、次に開いたとき新しいものになる。
- 帯: 1日目は出ない／2日目は出る／× で消える。

### ページの一覧（14枚＋入口）

`themes/<id>.html` と入口 `themes/index.html`。日本語の題は検索されやすい言い方にする。

| id | 題 | 国の決め方 |
|---|---|---|

| cross | 十字がある国旗 | 特徴データ |
| crescent | 三日月がある国旗 | 特徴データ |
| sun | 太陽がある国旗 | 特徴データ |
| animal | 動物・鳥がいる国旗 | 特徴データ |

| vtricolor | たて3色の国旗 | 特徴データ |

- 首都のテーマは作らない。
- **国旗の特徴データ** `data/flag_features.json`: 195か国それぞれに `stars / cross / crescent / sun / animal / unionjack / vtricolor / htricolor / redwhite` の当てはまるものを付ける。
  - 付け方: AI が1回目を付ける → **国旗の画像を並べた確認用ページ**（テーマごとに当てはまる国・当てはまらない国の境目を並べる）を作り、別の AI が画像を見て照らし合わせる → 食い違いだけ人の目（私）で決める。
  - 決まりを先に書く（例: 「十字」は国旗いっぱいの十字だけ。紋章の中の小さな十字は数えない。「赤と白だけ」は紋章の中の色も数える）。決まりはまとめページの本文にも書く。
- **見分け方の一言**（similar のページ）: 25グループそれぞれに1〜2文（例: 「インドネシアとモナコは色も形も同じ。違うのは縦横の比だけ」）。`data/similar_tips.json`。

### 1ページの中身

1. 題・1〜2文の説明（そのテーマの決まりも書く）
2. 国旗の一覧（国旗・国名。国名は国のページへのリンク）。ランキングは順位と面積も。
3. ［このテーマでクイズ］ボタン（下）
4. 「ほかのまとめ」へのリンク
5. 今のフッター（遊び方・運営者・お問い合わせ・プライバシーポリシー・国の一覧）。フッターに「国旗のまとめ」を足す。

- 作り方は国のページと同じ: `tools/make_theme_pages.mjs` が生成、出来たファイルはコミット、sitemap.xml の目印のあいだを書きかえる。
- 見た目は pages.css と country.css に合わせる。

### 「このテーマでクイズ」

- リンク先: `index.html#theme=<id>`。開くとモード選択に「テーマ: 星がある国旗（N か国）」が選ばれた状態で出る。
  - 地域の地図とチップの代わりに、テーマ名と［テーマをやめる］を出す。やめると今までの地域選びに戻る。
  - 出題はそのテーマの国だけ。問題数は 5/10/20/全部（全部＝テーマの国の数）。
  - 場所のモード（場所→国旗・国旗→場所・白地図タップ）の地図は全世界で出す。
- **タイムアタックは選べない**（ランキングの区分が増えるため。今の細かい地域と同じ扱い）。練習・挑戦はOK。
- テーマの選択は保存しない（次にプレイから入ったら、いつもの地域選び）。
- 出題の国が4か国未満になることはない（いちばん少ないテーマでも10か国以上になるよう、確認用ページで数える。10未満のテーマはページだけ作り、クイズのボタンは出さない）。

## E2 国ページを読み物に

今の国のページ（地域・面積・首都・ISO・豆知識・似ている国旗・この地域で遊ぶ）に足すもの:

1. **国旗の意味**（2〜3文）。色と模様が何を表すか。
   - `data/flag_meanings.json`（`a`・`t`・`note`＝出どころのメモ。trivia_facts.json と同じ形）。
   - 書き方: AI が書く → 別の AI 2体がそれぞれネットで出どころを確かめ、合わない・はっきりしないものは「〜とされる」と言い方を弱めるか、その部分を消す。公式の意味が決まっていない国は「公式には決まっていない」と書く。
2. **となりの国**（陸で国境を接している国）。国旗の小さい絵＋国名のリンク。島国は「陸で接している国はない（島国）」。
   - 地図データ（world.js）から計算する（topojson の neighbors）。生成のときに計算してページに書くので、ブラウザでは地図を読まない。
   - 地図データの都合で、細い国境が抜ける・海をはさんで付く国が出るかもしれない。計算結果を一覧にして確かめ、直しは `data/neighbors_fix.json` に書く。
3. **前の国・次の国**（同じ地域の中、五十音順）。ページの下に「← ○○　△△ →」。
4. **この国旗が出てくるまとめ**（E1 のページへのリンク。当てはまるものだけ）。
5. ページの description（検索結果の説明文）を「国旗の意味」から始まる文に変える。

- 首都の表示は今のまま（表示はOK、問題にはしない）。
- 足すのは生成スクリプトとデータだけ。index.html はさわらない。

## D3 英語版

### 範囲（最初の版）

英語の国旗クイズは世界中にたくさんあるので、まずは**クイズの核だけ**を英語にして、来る人がいるか見る。

| 英語にする | 日本語のまま／英語では隠す |
|---|---|
| ホーム（Play・Dictionary・Settings だけの小さい形） | 冒険（RPG）・バッジ・今日の難問・れんぞく日数・プロフィール・ランキング・タイムアタック |
| モード選択（5モード・練習・挑戦・地域・問題数） | 豆知識（答えのあとに出さない） |
| クイズ・結果画面 | ガチャ・コイン |
| 図鑑（一覧・地図） | 管理用サイト |
| 似た国旗の道場 | |
| 設定（画面の色・音・はやい送り） | |
| 国のページ195枚（英語版の E2 の中身。豆知識なし） | |
| まとめページ14枚 | |
| 遊び方・運営者・プライバシーポリシー | |

- 英語で遊んだ記録（正解の数など）は日本語版と同じ端末の記録に入る（同じサイトなので自然にそうなる）。ただし英語の画面ではバッジ・コインのお知らせを出さない。
- 英語版から日本語版へ、日本語版から英語版へ、ヘッダーの右に「日本語 / English」の切りかえ。
- 自動で英語へ飛ばすことはしない（Google が日本語ページを見られなくなるため）。日本語版を英語の端末で開いた人には、ホームに1行「English version →」を出す。

### しくみ

- URL は `/country-drill/en/`（`en/index.html`・`en/country/<a>.html`・`en/themes/<id>.html`・`en/howto.html` など）。
- **en/index.html は手で書かない**。`tools/make_en.mjs` が index.html から作る:
  - `<html lang="en">`、`<base href="../">`（js・css・flags を日本語版と同じファイルで使う）、画面の文字を辞書で置きかえ。
  - テスト: 「en/index.html が make_en.mjs の出力と同じ」こと。index.html を変えて作り直し忘れたら落ちる。辞書に無い日本語が en/index.html の画面に残っていたら落ちる。
- **js の中の文字**: `i18n.js` に `T(ja)` を作り、英語のときは辞書 `i18n-en.js` から引く（日本語のときは何もしない）。英語の画面に出る経路の文字だけ `T()` で包む。冒険・バッジなど英語で隠すものは包まない。
- **英語の国名**: countries.js に `e` を足す。決まり: 英語版 Wikipedia の記事名（例: Ivory Coast・Czech Republic・Eswatini・East Timor・Vatican City）。並びは英語のABC順。
- **検索**: 日本語と英語のページに `hreflang` で互いを書く。sitemap.xml に英語のページを足す。Search Console は同じ登録のままで英語も見られる。
- 地域名・細かい地域名・モード名などは辞書に入れる。

### 英語の文の確かめ

- 辞書は AI が作り、別の AI が「英語として自然か・国旗クイズとして意味が通るか」を確かめる。
- 国旗の意味（E2）の英語版も同じ。

### テスト

- 英語版で、ホーム → 5モードを1回ずつ遊べる。画面に日本語（かな・漢字）が出ていない（国名表示の欄も含む）。
- 英語版で冒険・バッジ・ランキングの入口が出ていない。
- 日本語版の今のテストは全部そのまま通る。

## チコに決めてほしいこと

それぞれ、おすすめと理由つき。全部おすすめでよければ「OK」だけで進める。

1. **英語版の範囲（D3）**
   - おすすめ: 上の表のとおり、クイズの核だけ（冒険・ランキング・今日の難問・バッジは日本語だけ）。
   - 理由: 全部を英語にすると文字が約3,000か所あり、手間が今の何倍にもなる。英語で来る人がいるか見てから広げても遅くない。ランキングを英語に出すと、名前の NG ワードも英語用が要る。
2. **英語の国名の決まり（D3）**
   - おすすめ: 英語版 Wikipedia の記事名（Ivory Coast・Czech Republic など）。
   - 理由: 英語で国旗クイズを探す人がいちばん見慣れた名前。正式名（Côte d'Ivoire・Czechia）より伝わる。
3. **アプリとして追加の帯を出すタイミング（D2）**
   - おすすめ: 2日目以降の人だけ、× で30日出さない。
   - 理由: 初めて来た人にいきなり「追加して」は押しつけがましい。気に入って戻ってきた人には効く。
4. **テーマでクイズにタイムアタックを付けるか（E1）**
   - おすすめ: 付けない（練習・挑戦だけ）。
   - 理由: ランキングの区分が14増えて、どれも人が少なくなる。細かい地域も同じ扱いにしている。
5. **白地図のズームボタンを外に出すのを、白地図タップだけにするか（F1）**
   - おすすめ: 白地図タップだけ。
   - 理由: ほかのモードは地図を押して答えないので、重なっても困らない。ほかまで変えるとスマホの見た目のテストを広く直すことになる。
6. **まとめページの数（E1）**
   - おすすめ: 上の14枚。
   - 理由: 特徴データ1つで9枚作れて、残り5枚は今あるデータで作れる。足すのはあとからでも同じ手間。

## 作らないもの

- グループランキング（D1）・こどもモード（D4）・独自ドメイン（E3）・C系の新しい問題（今回選ばれていない）。
- 英語の豆知識（779件の翻訳と確かめが大きいので、英語版に人が来てから）。
- 英語版のランキング・冒険・今日の難問。
