# 国旗クエスト（RPG）実装計画（計画 D）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** いつものクイズでコインを稼ぎ、旅人のレベルアップと国旗ガチャで強くなって、4択クイズのバトルで7つのダンジョンを攻略する RPG「国旗クエスト」を、index.html のフックにつなぐ4つの新しいファイルで足す。

**Architecture:** 計算はすべて DOM を触らない `rpg-core.js`（`globalThis.RPG_CORE`。node の `vm` で単体テストする）に置き、`rpg.js`（セーブ `RPG.tx`・コインの受け取り・入口・冒険ホーム・ガチャ・仲間・シェア）と `rpg-battle.js`（バトル）も、3つとも即時関数で包んで、計画 B の CustomEvent（`drill:*`）と `registerScreen` / `toast` / `#r-ext` / `#topbar-extra` だけで index.html とつながる。index.html に足すのは読み込みの4行だけで、RPG のファイルが読めなくてもクイズは今までどおり動く。

**Tech Stack:** 素の HTML/CSS/JS（ビルドなし）、d3（地図。既存の CDN 版）、テストは `node --test`（Node 22）・Playwright 1.63（`createRequire` でグローバルのものを使う）。

**Spec:** `docs/superpowers/specs/2026-10-26-rpg-design.md`（これが正）。バッジとの約束は `docs/superpowers/specs/2026-10-26-badges-design.md` §2.7・§5.1・§8・§9.2、PC の型は `docs/superpowers/specs/2026-10-26-pc-layout-design.md` §5.10、イベントの約束は `docs/events.md`（計画 B が作り、計画 C が書き足したもの）。

式（設計書 §4・§7.2）:

- 通常: `hp = atk(R)*enemyHits`、`atk = ceil(hp(R)*enemyHitPct)`。ボス: `flagHp = atk(R)`、`atk = ceil(hp(R)*bossHitPct)`（`R` は推奨 Lv、`atk(R)` `hp(R)` は `heroStats(R)`）

- `cardAtk = base[star] * (1 + stack*stackN) * (1 + fr*frN) * (bonus ? regionMul : 1)`。地域ボーナスは「カードの国の地域 === ダンジョンの `r`」か、ダンジョンが world

- `battleStats`: `Σ = party の atk の和`、`g = d.gauge[id + ':' + floor] || 0`、`atk = round((hero.atk + round(Σ)) * (1 + gaugeStep*g))`、`hp = round((hero.hp + round(hpMul*Σ)) * (1 + gaugeStep*g))`
- `hitsNeeded`: 通常はコンボ 0,1,2… の `damage(atk, k, false)` を足して `hp` に届く回数。ボスは `flags * ceil(flagHp / atk)`。`missesAllowed = floor((hp - 1) / en.atk)`

- `floorsOf`: 地域の国を `ar` の大きい順にし、`i = 0..3` で `slice(round(n*i/4), round(n*(i+1)/4))` の国コード
- `capOK(c)`: 国名 `c.n` と首都 `c.c` が「同じ」「片方がもう片方をふくむ」「先頭2文字が同じ」のどれでもない
