# B8 見やすさ設定（色の見分けやすさ・文字の大きさ）実装計画

チコ依頼（2026-10-29「B8」）。設計はこの計画の「決めたこと」がすべて（別の設計書は無い）。

## 決めたこと

1. 設定画面の「画面の色」のすぐ下に「見やすさ」の欄を足す。
   - **文字の大きさ**: チップ3つ［ふつう］［大きめ］［とても大きい］。`settings.fs` = `'m'`（既定）/`'l'`/`'xl'`。
     `<html data-fs="l|xl">` を付け、`html[data-fs="l"] { font-size: 112.5% }`、`html[data-fs="xl"] { font-size: 125% }`。`'m'` は属性なし（今と1pxも変わらない）。
     テーマと同じく head の先読みスクリプトで最初から付ける（ちらつき防止）。
   - **色の見分けやすさ**: チェックボックス（既定 OFF）。`settings.cvd = true` で `<html data-cvd>`。
     ON のとき正解/不正解の色を青/オレンジ系に置きかえる（Okabe–Ito: 正解 `#0072B2`、不正解 `#D55E00`、ダークは 正解 `#56B4E9`・不正解 `#E69F00`。soft 色もそれに合わせて作る）。ドパガキ ON でも cvd を優先（`body.dopa` の --ok/--ng より強く）。
     色の変数は「:root」「prefers-color-scheme dark（:root:not([data-theme=light])）」「[data-theme=dark]」の3か所の決まりに合わせて、cvd 版も3か所に書く。
2. 色だけに頼らない印を **いつでも**（設定に関係なく）付ける: 選択肢 `.choice.ok` に「✓」、`.choice.ng` に「✗」を ::after で右上に小さく。国旗の選択肢でも国旗を隠さない位置・大きさ。答えの欄の「正解／ざんねん」の文字はすでにあるのでそのまま。
3. 国旗の絵そのものは変えない（本物の色が答えなので）。
4. 文字が大きいときは PC でも縦スクロールが出てよい（ふつうのときの「縦スクロールなし」のテストはそのまま守る）。横スクロールはどの大きさでも出さない（スマホ 360/390px、PC 1366）。
5. 引き継ぎ（プロフィール移行）は settings ごと移っているならそのまま。管理用サイトのセーブ検査（admin-save.js の settings の形）が新しいキーを拒まないか確かめ、拒むなら足す。
6. ?v= を上げるファイルは今の main の値+1。

## タスク

### Task 1: 設定の保存と html の属性
- `S` の既定に `fs: 'm', cvd: false` を足す。`applyA11y()` で `data-fs`・`data-cvd` を付け外し。head の先読みスクリプトにも同じ処理（try で包む）。
- unit/e2e: 既定は属性なし、`fs:'l'` で読み込むと最初から `data-fs="l"`、変な値は無視。

### Task 2: 設定画面の UI
- 「見やすさ」の欄（見出し・チップ3つ・チェックボックス・一言の説明「正解は青、まちがいはオレンジになります」）。ライト/ダーク両方で見やすく。
- e2e: チップを押すと html の font-size が 18px/20px（ふつう16px）、チェックで data-cvd、再読み込みで残る。

### Task 3: 色と印
- cvd 版の色変数（3か所＋dopa より強く）。地図の正解/外れ（tapmap の .on/.ngc/.tapx/.tapline、出題地図）・ランキングのエラー文など --ok/--ng を使う所は変数経由なので自動で変わることを確かめる。
- ✓/✗ の印（いつでも）。
- e2e: cvd ON で `.choice.ok` の border-color が #0072B2 系、OFF で今の色。印が出る。

### Task 4: 大きい文字での崩れチェック
- `xl` で 360×640・390×844・1366×657 のホーム・モード選択・クイズ（4択・国旗）・結果・設定・図鑑・冒険ホームを開き、横スクロールなし・ボタンが画面外に出ないことを e2e で確かめ、崩れたら CSS を直す。
- README/howto に1行（設定で文字の大きさと色を変えられる）。
