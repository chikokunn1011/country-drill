# 国旗クエスト 第3章「宇宙」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 鏡の地図喰いを倒したあとに開く第3章「宇宙」（テーマ別の7つの星・場所多めの出題・太陽系のマップ・エンディング）を入れる。

**Architecture:** 第2章と同じく `DUNGEONS` の後ろに `ch: 3` の7つを足す（ステージ71〜105）。宇宙のダンジョンは地域ではなく「テーマ」（`t`）で国をしぼるので、`dg.r` を直接見ていた所（国の袋・ボスの旗・地域ボーナス・選択肢）を `rpg-core.js` の `poolOf(dg)` / `inDungeon(dg, a)` に寄せる。冒険マップは章3だけ世界地図のかわりに太陽系の SVG。

**Tech Stack:** 素の JS（クラシック script）、d3（地球の冒険マップ）、node:test、Playwright、PostgreSQL 16

**Spec:** `docs/superpowers/specs/2026-10-28-rpg-story-next-design.md`（§2・§3・§5・§7・§8、§9 の2つ目）

## Global Constraints

- 出題は国旗・国名・場所だけ（f2n・n2f・m2f）。首都は問わない
- 数値は全部 `TUNING`（`rpg-core.js`）に置く
- `rpg-*.js` はクラシック script。外側に `const` / `let` / `function` を書かない
- 画面の文はやさしい日本語（今の冒険の口調）。ファイル名は半角英数字
- 変えた JS / CSS は `index.html` の `?v=` を1つ上げる（それを見ている e2e も合わせる）
- 冒険ランキングの SQL は第2章で 21 ダンジョン・105 フロア・Lv99 まで広げ済み。**SQL の変更は無し**
- テスト: `node --test 'tests/unit/*.test.mjs'`、`node --test --test-concurrency=1 'tests/e2e/<file>.test.mjs'`（`tests/e2e` で `npm ci` 済みにしてから。playwright install はしない）、`bash tests/sql/run.sh`
- 地球・鏡の地球の遊び方（国の袋・選択肢・地域ボーナス・形式の順）は変えない

## Review Focus

1. 鏡の地球の途中や、鏡の地図喰いを倒し済みのセーブを読んでも何も消えず、倒し済みの人には「第3章のはじまり」のストーリーが1回だけ出て宇宙が開く → Task 3 `story_ch3start_for_old_mirror_clear`
2. テーマの国が少ない星（土星 39か国）でも、F1〜F4 の袋・ボスの旗（flags 枚）・選択肢4つがいつもそろう → Task 1 `space_pools_fill`
3. 宇宙で苦手な国（テーマ外）が袋に混ざらない → Task 1 `space_bag_stays_in_theme`
4. 地域ボーナスは宇宙ではテーマに入る国だけ（全員ではない）。バトル画面の仲間の表示も同じ → Task 1 `space_theme_bonus`、Task 2 `space_party_bonus_mark`
5. 星喰いを倒したあと「全クリア！」になり、次のフロアが無い → Task 3 `all_clear_after_space`

### Task 1: 宇宙の7つの星とテーマ（rpg-core.js）

**Files:**
- Modify: `rpg-core.js`（`TUNING`・`DUNGEONS`・`MONSTERS`・`CHAPTERS`・`STORY_IDS`・`recLv`・国の袋/ボス/ボーナス・形式・exports）
- Test: `tests/unit/rpg-core.test.mjs`

**Interfaces:**
- Produces:
  - 宇宙の id（この順で今の14個の後ろ）: `moon` `mercury` `venus` `mars` `jupiter` `saturn` `blackhole`。それぞれ `ch: 3`・`r: 'all'`・`t`（テーマキー。`blackhole` は無し）
  - `THEMES = { island: { n: '島国', a: [...] }, small: {...}, equator: {...}, landlocked: {...}, big: {...}, south: {...} }`（`n` は答えのあとに出す名前）
  - `poolOf(dg) -> string[]`（そのダンジョンで出す国。テーマがあればテーマの国、無ければ今の `codesOf(dg.r)`）
  - `inDungeon(dg, a) -> boolean`（地域ボーナスの判定。テーマがあればテーマに入るか、無ければ今の `dg.r === 'all' || 地域が同じ`）
  - `themeChoices(a, dg, rng) -> string[4]`（テーマの国から3つ＋a、足りなければ全部から。シャッフル）
  - `modeCycle(floor, ch)`・`nextMode(mode, floor, ch)`・`bossMode(k, ch)`（ch 省略時は今と同じ）
  - `CHAPTERS` に `{ ch: 3, name: '宇宙', e: '🪐', last: 'blackhole' }`、`STORY_IDS = ['ch1', 'ch2', 'ch3start', 'ch3']`
  - `TUNING.battle.recStep3 = 0.85`

test('space_dungeons', () => {
  assert.deepEqual(K.DUNGEONS.slice(14).map(g => g.id), ['moon', 'mercury', 'venus', 'mars', 'jupiter', 'saturn', 'blackhole']);
  assert.deepEqual(K.DUNGEONS.slice(14).map(g => g.t ?? null), ['island', 'small', 'equator', 'landlocked', 'big', 'south', null]);

  assert.equal(K.recLv(70), 69); assert.equal(K.recLv(71), 70); assert.equal(K.recLv(105), 99);   // 69 + round((s-70) × 0.85)

test('themes', () => {
  const n = k => K.THEMES[k].a.length;
  assert.deepEqual([n('island'), n('small'), n('equator'), n('landlocked'), n('big'), n('south')], [38, 40, 51, 44, 40, 39]);

  assert.deepEqual(K.modeCycle(1), ['f2n', 'n2f']);                 // 地球は今のまま

  assert.equal(K.nextMode('m2f', 1, 3), 'f2n'); assert.equal(K.nextMode('f2n', 1, 3), 'm2f'); assert.equal(K.nextMode('n2f', 4, 3), 'm2f');
