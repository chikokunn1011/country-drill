# 国旗クエスト 仲間の編成・チームボーナス・バトル中の仲間・かざり 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 仲間の編成（最大5枠・コインで購入）、13グループのチームボーナス、バトル中の仲間表示と援護の演出、プロフィールのかざり（冒険ランキングにも表示）を足す。

**Architecture:** 計算は `rpg-core.js`（純粋関数・単体テスト）に足し、編成画面は新しい `rpg-team.js`（`rpg-cards.js` と同じ `addScreen` 方式で `<section>` を自分で作る）。バトルは `rpg-battle.js` の登場画面と上部バーを直す。かざりは rpg.js の冒険ホーム、送信と表示は `ranking.js`・`rpg-rank.js`、DB は `supabase/schema.sql` に drop 無しで足す。

**Tech Stack:** 素の JS（クラシック script の IIFE）、CSS、Supabase（PostgreSQL 16 / PostgREST）、node:test、Playwright e2e。

**Spec:** `docs/superpowers/specs/2026-10-27-rpg-teams-design.md`

## Global Constraints

- ファイル名は半角英数字だけ。新しいファイルは `rpg-team.js` と `tests/e2e/rpg_team.test.mjs` の2つ。
- 本物のお金は使わない。枠の購入はゲーム内コイン（●）だけ。
- 国旗は揺らさない・回さない・破らない・逆さにしない。動かすのはカードの枠（`.rpg-pc` / `.rpg-card`）だけ。
- 出題は国旗・国名・場所だけ（首都の出題は作らない）。
- 一度も編成を組んでいないセーブの強さは今と同じ（`teams` が無い・おまかせ＝`party()` の3枚）。
- セーブの `v` は 1 のまま（`VERSION`・`MIGRATE` は変えない）。
- `rpg-core.js` が足すグローバルは `RPG_CORE` だけ（テスト `iife_wrapped`）。
- 画面に出す利用者の文字（枠の名前・ニックネーム）は必ず `esc()`。`flag(a)` に渡す前に国コードを `byA.has(a)` でしぼる。
- 値: `TUNING.team = { slots: 5, slotCost: [2000, 3000, 4000, 5000], bonus: [0, 0, 0.10, 0.25], nameMax: 8 }`。
- 変えたファイルは、それを読む index.html の行の `?v=` を同じコミットで上げる（docs/events.md §9 の決まり）。
- 本番 DB には触らない（PR のときにチコの OK をもらってから別に適用する）。
- テスト: `node --test 'tests/unit/*.test.mjs'`、`node --test 'tests/e2e/*.test.mjs'`、`bash tests/sql/run.sh`。e2e の CDN 差し替えは tests/e2e/helpers.mjs のまま使う。`rpg_battle`・`rpg_layout`・`rpg_rank` の既存テストを全部通したままにする。

## Review Focus

1. **古いセーブ（`teams`・`tsel`・`deco` が無い）** → 今と同じ強さ・同じおまかせ3枚で動く。Task 1 の `old_save_same_strength`。
2. **枠に持っていない国・知らない国コード・重なりが入ったセーブ**（引き継ぎコードや手で壊したデータ）→ 知らないコードと重なりは sanitize で消え、持っていない国は使うときだけ外れる。Task 1 の `sanitize_teams_garbage` と `team_party_skips_unowned`。
3. **コインがちょうど値段・1足りない・枠がもう5つ** → ちょうどなら買える、足りない・上限なら何も変わらない。Task 1 の `buy_slot_edges`、Task 2 の `buy_slot_disabled_when_short`。
4. **readOnly のセーブ（新しい版のデータ）** → 編成画面で入れる・外す・買う・名前変更・登場画面の切り替えをしても例外が出ず、セーブも変わらない。Task 2 の `readonly_no_write`。
5. **DB にまだ `top_rpg2` が無い（本番に適用する前）** → ランキングは `top_rpg` にもどして今どおり出る（かざり無し）。Task 6 の `falls_back_to_top_rpg`。

  - `buySlot(d): number`（払った額。買えなかったら 0。買えたら `teams.push({ n: '編成' + 新しい数, c: null })`、`tsel` を新しい枠に）
  - `TUNING.team`（Global Constraints の値）
  - `fresh()` に `teams: [{ n: '編成1', c: null }], tsel: 0, deco: []`
- `party(d, id)` は変えない。
