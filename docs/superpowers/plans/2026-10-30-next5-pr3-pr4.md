# 改善5案 PR3（テーマ別まとめページ）・PR4（国ページを読み物に）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 検索から人が来る「国旗のまとめ」ページ14枚と、そのテーマで遊べるクイズの入口を作り（PR3）、国のページ195枚に国旗の意味・となりの国・前後の国・まとめへのリンクを足す（PR4）。

**Architecture:** データ（`data/flag_features.json`・`data/similar_tips.json`・`data/flag_meanings.json`・`data/neighbors_fix.json`）を人と AI で作って確かめ、生成スクリプト（新しい `tools/make_theme_pages.mjs`、今の `tools/make_country_pages.mjs`）が静的ページと、ブラウザ用の `themes.js` を書く。本編（index.html）は `themes.js` を読み、`#theme=<id>` でテーマのクイズを始められる。PR3 をマージしてから PR4 を main に載せ直す。

**Tech Stack:** 素の JS・Node（node:test、node:vm）、topojson-client（tests/e2e/node_modules の 3.1.0 を生成スクリプトから使う）、Playwright。

**Spec:** `docs/superpowers/specs/2026-10-29-next5-design.md`（E1・E2 の節）

## Global Constraints

- 問題に出すのは国旗・国名・場所だけ。首都のテーマ・首都を問う問題は作らない（国のページで首都を「表示」するのは今のまま）。
- まとめは14枚: `stars` 星がある国旗／`cross` 十字がある国旗／`crescent` 三日月がある国旗／`sun` 太陽がある国旗／`animal` 動物・鳥がいる国旗／`unionjack` ユニオンジャックが入った国旗／`vtricolor` たて3色の国旗／`htricolor` よこ3色の国旗／`redwhite` 赤と白だけの国旗／`similar` 似ている国旗の見分け方／`island` 島国の一覧／`landlocked` 内陸国の一覧／`bigarea` 面積が大きい国ランキング（上位20）／`smallarea` 面積が小さい国ランキング（下位20）。
- テーマの国が10か国未満なら、ページは作るがクイズのボタンは出さない（`themes.js` にも入れない）。
- テーマでクイズは練習・挑戦だけ（タイムアタックは選べない）。テーマの選択は保存しない。場所のモードの地図は全世界。
- テーマのクイズの `drill:*` イベントの `region` は `'theme:<id>'`（受け取る側は知らない地域として扱う＝地域のバッジに入らない）。docs/events.md に書く。
- 生成物（`themes/*.html`・`country/*.html`・`themes.js`・`sitemap.xml`）はコミットする。同じ入力ならいつも同じ出力（日付・乱数を使わない）。
- 生成物が最新かはユニットテストで見る（`render(readInputs(ROOT))` と今のファイルが同じ）。
- 新しい色は作らない。見た目は pages.css・country/country.css に合わせる。
- 変えた js/css は `?v=` を「main の数 +1」。PR2 が入っていれば `node tools/make_sw.mjs` で sw.js も作り直す（`themes.js` は precache に入る）。
- 事実の文（国旗の意味・見分け方）は、別々の AI 2体がネットで出どころを確かめる。合わない・はっきりしない所は「〜とされる」に弱めるか消す。各行に `note`（出どころのメモ）を残す。
- 画面の文は今のページに合わせたやわらかい言い方（ですます無し）。

## Review Focus

1. **特徴の付け間違い**（例: 紋章の中の小さな十字を「十字」に入れる）: 決まりを `data/flag_features.json` の先頭の `rules` に書き、確認用ページで画像を見て照らし合わせる。Task 1 の `features_rules_examples` で代表例を押さえる。
2. **`#theme=` に知らない id・壊れた %**: 何もせずホーム（今の `#play=` と同じ）。Task 4 の `theme_hash_unknown`。
3. **テーマのクイズ中に設定や地域チップをさわる**: 地域チップは出さない。［テーマをやめる］で今の地域選びに戻る。Task 4 の `theme_leave`。
4. **島国のとなりの国**: 「陸で接している国はない（島国）」と出し、空の見出しを出さない。地図データで海をはさんだ国がとなりに出たら `neighbors_fix.json` で消す。Task 6 の `neighbors_island` と `neighbors_fix_applied`。
5. **前後の国が地域の端**: 最初の国には「前」が無く、最後の国には「次」が無い（ぐるっと回さない）。Task 7 の `prevnext_edges`。
