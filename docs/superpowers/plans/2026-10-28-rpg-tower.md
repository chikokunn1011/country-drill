# 国旗クエスト「英雄の塔」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 地図喰いを倒すと開く、終わりのない「英雄の塔」（HP 持ち越し・10階ごとに中ボス・最高到達階のランキングとバッジ）を入れる。

**Architecture:** 塔はストーリーのダンジョン（`DUNGEONS`）には入れず、`rpg-core.js` に塔だけの計算（強さ・袋・形式・回復・ごほうび・敵）を足す。バトル画面（`rpg-battle.js`）は今のバトルの画面と答え合わせを使い、始め方・袋の補充・形式の選び方・終わり方だけ塔用の道を持つ（`B.tower` があるときに分かれる）。記録は Supabase の `rpg_players` に `tower`・`tower_at` 列を足し、今の記録（`rpg_update`）・かざり（`rpg_set_deco`）とは別の関数で送る。

**Tech Stack:** 素の JS（クラシック script）、node:test、Playwright、PostgreSQL 16、Supabase

**Spec:** `docs/superpowers/specs/2026-10-28-rpg-story-next-design.md`（§6、§8 の塔のセーブ、§9 の3つ目）

## Global Constraints

- 出題は国旗・国名・場所だけ（f2n・n2f・m2f）。首都は問わない
- 数値は全部 `TUNING.tower`（`rpg-core.js`）に置く
- `rpg-*.js` はクラシック script。外側に `const` / `let` / `function` を書かない
- 画面の文はやさしい日本語（今の冒険の口調）。ファイル名は半角英数字
- 変えた JS / CSS は `index.html` の `?v=` を1つ上げる（それを見ている e2e も合わせる）
- SQL は `create or replace` と `alter table ... add column if not exists` と `create index if not exists` だけ（drop しない、今の関数の形も変えない）。本番 DB への適用はチコの明示OKのあと、サイトの公開より先
- ストーリー（地球・鏡の地球・宇宙）の遊び方・コイン・セーブ・バッジの判定は変えない
- テスト: `node --test 'tests/unit/*.test.mjs'`、`node --test --test-concurrency=1 tests/e2e/<file>.test.mjs`（1ファイルずつ）、`bash tests/sql/run.sh`

## 塔のルール（設計書 §6 とチコの決定）

- 地図喰い（`world` のボス）を倒すと開く（`towerOpen(d)` ＝ `(d.floors.world || 0) >= 5`）。何度でも挑める。始めると1階から
- 1つの階 ＝ ストーリーの通常フロアと同じ大きさのバトル1回（敵の強さは `enemy()` と同じ式で、ステージ番号のかわりに塔の推奨 Lv を使う）
- 塔の f 階の推奨 Lv ＝ `1 + floor((f − 1) × 1.0)`（上限なし）
- HP は階をまたいで持ち越し。階を上がるたびに最大 HP の 10% 回復（最大を超えない）。10階ごとに中ボス（旗の枚数 ＝ `min(12, 5 + f / 10)`）、中ボスを倒すと HP 全回復
- HP が 0 で終わり（復活なし）。途中で［やめる］・ページを閉じると、その回はそこで終わり（続きからは再開しない）
- 出題は全世界。**21階から、1問ごとに 50% の確率でその問題の4択を似た旗（`similarChoices`）にする**。51階から形式を宇宙の順（`m2f, f2n, m2f, n2f`）に。中ボスの旗・まちがえた問題の出し直しも同じ順
- 仲間・編成は今のもの。地域ボーナスは全員（全世界ダンジョンと同じ）。がんばりゲージは塔では使わない・増やさない
- **最高記録（`tower.best`）＝ これまでに勝った（クリアした）いちばん上の階**（2026-10-28 チコ決定「4階で死んだら3階が最高スコア」）。f 階を勝った時点で `best = max(best, f)` を保存する。ランキング・バッジ・終わりの画面の「n階まで」は全部この数
  - 例: 3階まで勝って4階で負け → 「3階まで」、best 3。3階を勝ったところで［やめる］→ 「3階まで」、best 3。1階で負け → 「0階」ではなく「1階でたおれた」と出し、best は変えない
- ごほうび: 1階勝つごとに `5 + f` コイン。さらに、はじめて勝った階（`f > best`）なら 20 コイン。best は勝つたびに上がるので、ボーナスは1つの階で1回だけ（別の `paid` は持たない）
- 1階ごとの勝ち負けは今のバトルと同じく `settleRun` を通す（覚えた国・なかよし度・仲間入り・手配書・苦手の克服が塔でも進む）。勝ち負けのコインは `battleReward` ではなく上の塔のごほうびだけ。負けた階のがんばり賞は無し

## イベントと記録の決まり（全タスク共通）

- 1階終わるごとに `rpg:battle` を出す: `{ dungeon: 'tower', floor: f, boss, win, ... }`（今の detail と同じ形）。**`rpg:clear` は出さない**
- コインは `rpg:coins` の reason `'tower'`（新しい reason。`docs/events.md` に書く）
- 1階終わるごとに `rpg:tower` `{ floor, win, best, newBest, coins }`（`coins` はその階でもらった合計＝基本＋ボーナス、`newBest` はその回で best が増えたか）、回が終わったら `rpg:tower-end` `{ cleared, best }`（`cleared` ＝ その回で勝ったいちばん上の階、0 もある）
- `st` は `win`・`lose` だけ数える（`bossWins`・`nodmg`・`combo` の記録は塔では動かさない）
- `badges.js` は `rpg:battle` の `dungeon === 'tower'` を、ボス・無傷・格上（underdog）系の判定に使わない（初勝利・知識こそ力などの答えの数え方は今のまま）
- `RPG.snapshot()` に `tower: d.tower.best` を足す（`docs/events.md` §7 の形も直す）

## Review Focus

1. 塔を開いていない（地図喰いを倒していない）セーブでは、入口が「地図喰いをたおすと開く」で押せず、`RPG_BATTLE.startTower()` も false → Task 1 `tower_open`、Task 2 `tower_locked_until_world`
2. 階のあいだで HP がちゃんと持ち越され（回復は最大を超えない）、中ボスのあとは全回復 → Task 1 `tower_heal`、Task 2 `tower_hp_carries`・`tower_midboss_full_heal`
3. 塔の途中でページを閉じても、それまでのコインと `tower.best`（勝った階）は残る → Task 2 `tower_reload_keeps_best`
4. 前からのセーブ（`tower` が無い）を読むと `{ best: 0 }` になり、ほかは何も変わらない。壊れた値も直る → Task 1 `tower_sanitize`
5. はじめて勝った階のボーナス 20 は1回だけ（2回目の挑戦の1階は +6 だけ） → Task 1 `tower_reward`、Task 2 `tower_first_floor`・`tower_quit_keeps_best`
6. 塔の記録の送信は、今の記録・かざりの送信と 10 秒制限を取り合わない（別の `tower_at`）。サーバーは小さい値で上書きしない → Task 3 SQL テスト
7. 塔の階がストーリーのバッジ（ボス・無傷・格上）や `rpg:clear` を動かさない → Task 2 `tower_no_story_side_effects`

  - `TOWER_MONSTERS`: 通常の敵の並び（今の `MONSTERS` の通常の敵を地球の7ダンジョンから順に並べたもの）と中ボス `{ e: '🗼', n: '塔の番人' }`。`towerMonster(f)` ＝ 中ボスの階なら中ボス、ほかは並びの `(f − 1) % 長さ` 番目

  - `towerRecLv(f)`、`towerEnemy(f) -> { boss, s: f, recLv, hp?, atk, flags?, flagHp? }`（`enemy()` と同じ形。`enemy()` の中身を「推奨 Lv → 敵の数値」の小さい関数 `enemyAt(R, boss, flags)` に分けて両方から使う）
  - `towerIsBoss(f)`（`f % bossEvery === 0`）、`towerBossFlagsN(f)` ＝ `min(bossFlagsMax, bossFlags0 + floor(f / bossEvery))`
  - `towerHeal(hp, maxHp, clearedFloor)`（中ボスの階を勝ったら maxHp、ほかは `min(maxHp, hp + ceil(maxHp × healPct))`）
  - `towerModes(f)`（f < spaceFrom は `modeCycle(3)` ＝ `['f2n','n2f','m2f']`、spaceFrom から `SPACE_CYCLE`）、`towerNextMode(mode, f)`（`nextMode` と同じ回し方を `towerModes(f)` で）、`towerBossMode(k, f)` ＝ `towerModes(f)[k % 長さ]`
  - `towerBag(d, m, f, rng) -> [{ a, mode, tag }]`: 全世界からシャッフルで `bagSize` か国 → `battleBag` と同じ決まりで、残りの国から苦手な国を `weakMax` まで足し、手配書のまだの国を `tag: 'wanted'` で足す。形式は `towerModes(f)` を順に。`battleBag` の国の選び方は「この階の国・残りの国・形式の順」を引数で受け取る共通の関数に分けて両方から使う
  - `towerRefill(f, lastMode, rng)`: 全世界から `bagSize` か国、形式は前の形式がある国は `towerNextMode(last[a], f)`、無い国は `towerModes(f)` を順に（全部同じ形式にしない）
  - `towerFlags(d, m, f, rng)`: `bossFlags` と同じ選び方を全世界から、枚数は `towerBossFlagsN(f)`（`bossFlags` も共通の関数に）
  - `towerSimilar(f, rng)`（f ≥ similarFrom のとき `rng() < similarRate`）
  - `towerReward(f, best) -> { coins, bonus }`（`coins = coinBase + f`、`f > best` なら `bonus = bestBonus`、ほかは 0。best は勝つ前の値）
  - `towerStats(d, t = d.tsel)` ＝ `battleStats(d, 'world', 0, t)` から `gauge` を 0 にしたもの（全員に地域ボーナス、ゲージなし）
  - セーブ `tower: { best: 0 }`。`sanitize` で 0〜`maxFloor` の整数に（数の文字列は数に、小数は四捨五入、ほかは 0）。ほかのキーは捨てる
