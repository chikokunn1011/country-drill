# 国旗クエスト「英雄の塔」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 地図喰いを倒すと開く、終わりのない「英雄の塔」（HP 持ち越し・10階ごとに中ボス・最高到達階のランキングとバッジ）を入れる。

**Architecture:** 塔はストーリーのダンジョン（`DUNGEONS`）には入れず、`rpg-core.js` に塔だけの計算（強さ・袋・形式・回復・ごほうび）を足す。バトル画面（`rpg-battle.js`）は今のバトルを1階として使い、勝つと HP を持ち越して次の階を続けて始める「塔モード」を持つ。記録は Supabase の `rpg_players` に `tower` 列を足し、今の記録（`rpg_update`）とは別の関数で送る（かざりの `rpg_set_deco` と同じやり方）。

**Tech Stack:** 素の JS（クラシック script）、node:test、Playwright、PostgreSQL 16、Supabase

**Spec:** `docs/superpowers/specs/2026-10-28-rpg-story-next-design.md`（§6、§8 の塔のセーブ、§9 の3つ目）

## Global Constraints

- 出題は国旗・国名・場所だけ（f2n・n2f・m2f）。首都は問わない
- 数値は全部 `TUNING.tower`（`rpg-core.js`）に置く
- `rpg-*.js` はクラシック script。外側に `const` / `let` / `function` を書かない
- 画面の文はやさしい日本語（今の冒険の口調）。ファイル名は半角英数字
- 変えた JS / CSS は `index.html` の `?v=` を1つ上げる（それを見ている e2e も合わせる）
- SQL は `create or replace` と `alter table ... add column if not exists` だけ（drop しない、今の関数の形も変えない）。本番 DB への適用はチコの明示OKのあと、サイトの公開より先
- ストーリー（地球・鏡の地球・宇宙）の遊び方・コイン・セーブは変えない
- テスト: `node --test 'tests/unit/*.test.mjs'`、`node --test --test-concurrency=1 'tests/e2e/<file>.test.mjs'`（1ファイルずつ）、`bash tests/sql/run.sh`

## 塔のルール（設計書 §6 とチコの決定）

- 地図喰い（`world`）を倒すと開く。何度でも挑める。始めると1階から
- 1つの階 ＝ ストーリーの通常フロアと同じ大きさのバトル1回（`enemy()` と同じ式。ステージ番号のかわりに塔の推奨 Lv を使う）
- 塔の f 階の推奨 Lv ＝ `1 + floor((f − 1) × 1.0)`（上限なし）
- HP は階をまたいで持ち越し。階を上がるたびに最大 HP の 10% 回復。10階ごとに中ボス（旗の枚数 ＝ `min(12, 5 + f / 10)`）、中ボスを倒すと HP 全回復
- HP が 0 で終わり（復活なし）。途中でやめる・閉じると、その回はそこで終わり
- 出題は全世界。21階から選択肢の半分を似た旗（`similarChoices`）、51階から形式を宇宙の順（`m2f, f2n, m2f, n2f`）に
- 仲間・編成は今のもの。地域ボーナスは全員（全世界ダンジョンと同じ）
- ごほうび: 1階勝つごとに `5 + f` コイン。自己ベストを超えた階は、さらに 1階につき 20 コイン（はじめて届いた階だけ）
- 記録: `tower.best` ＝ 勝った（クリアした）いちばん上の階

## Review Focus

1. 塔を開いていない（地図喰いを倒していない）セーブでは、入口が「地図喰いをたおすと開く」で押せず、開発用の API 以外から始められない → Task 2 `tower_locked_until_world`
2. 階のあいだで HP がちゃんと持ち越され（回復は最大を超えない）、中ボスのあとは全回復 → Task 1 `tower_heal`、Task 2 `tower_hp_carries`
3. 塔の途中でページを閉じても、それまでに勝った階のコインと `tower.best` は残る（勝つたびに保存） → Task 2 `tower_reload_keeps_best`
4. 前からのセーブ（`tower` が無い）を読むと `{ best: 0, paid: 0 }` になり、ほかは何も変わらない。壊れた値（マイナス・文字・巨大な数）も直る → Task 1 `tower_sanitize`
5. 冒険ランキングの塔の記録は、登録していない人・塔に登ったことがない人（0階）では送らず、サーバーは今の記録より小さい値で上書きしない → Task 3 SQL テスト

### Task 1: 塔の計算（rpg-core.js）

**Files:**
- Modify: `rpg-core.js`（`TUNING.tower`・塔の関数・`fresh`/`sanitize` の `tower`・exports）
- Test: `tests/unit/rpg-core.test.mjs`

**Interfaces:**
- Produces:
  - `TUNING.tower = { recStep: 1.0, bossEvery: 10, bossFlags0: 5, bossFlagsMax: 12, healPct: 0.1, coinBase: 5, bestBonus: 20, similarFrom: 21, similarRate: 0.5, spaceFrom: 51, maxFloor: 100000 }`
  - `TOWER = { id: 'tower', r: 'all', name: '英雄の塔', flags: 12 }`（`DUNGEONS` には入れない。`inDungeon(TOWER, a)` は全員 true）
  - `towerRecLv(f) -> number`、`towerEnemy(f) -> { boss, s: f, recLv, hp?, atk, flags?, flagHp? }`（`enemy()` と同じ形）
  - `towerIsBoss(f) -> boolean`（10 の倍数）
  - `towerHeal(hp, maxHp, clearedFloor) -> number`（中ボスの階を勝ったら maxHp、ほかは `min(maxHp, hp + ceil(maxHp × healPct))`）
  - `towerBag(d, m, f, rng) -> [{ a, mode, tag }]`（全世界から。苦手な国の混ぜ方は `battleBag` と同じ。形式は `towerModes(f)` の順）
  - `towerModes(f) -> string[]`（f < 51 は `modeCycle(4)`、51 から `['m2f','f2n','m2f','n2f']`）
  - `towerFlags(d, m, f, rng) -> string[]`（`bossFlags` と同じ選び方で、枚数は `min(12, 5 + f/10)`）
  - `towerSimilar(f, rng) -> boolean`（21階から `similarRate` の確率で true）
  - `towerReward(f, best) -> { coins, bonus }`（`coins = coinBase + f`、`f > best` なら `bonus = bestBonus`、ほかは 0）
  - `towerStats(d) -> battleStats と同じ形`（全世界ダンジョンと同じ地域ボーナス、がんばりゲージなし）
  - セーブ `tower: { best: 0, paid: 0 }`（`paid` は更新ボーナスを払った最高の階。`sanitize` で 0〜`maxFloor` の整数）
