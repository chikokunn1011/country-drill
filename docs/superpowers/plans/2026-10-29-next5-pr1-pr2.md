# 改善5案 PR1（白地図タップの直し）・PR2（アプリ化）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 白地図タップをスマホで押しやすく・キーボードで答えられるようにし（PR1）、サイトをオフラインで遊べるアプリ（PWA）にする（PR2）。

**Architecture:** PR1 は index.html の `tapMap()` と CSS だけを変える。PR2 は `sw.js`（service worker）と、その一覧を作る `tools/make_sw.mjs`、登録と「アプリとして追加」の帯を受け持つ `pwa.js` を足す。PR1 と PR2 は別々の PR（PR1 をマージしてから PR2 を main に載せ直す）。

**Tech Stack:** 素の JS（ビルドなし）、d3 7.9.0 の zoom、Service Worker API、node:test、Playwright（グローバル）。

**Spec:** `docs/superpowers/specs/2026-10-29-next5-design.md`（F1・D2 の節）

## Global Constraints

- 問題に出すのは国旗・国名・場所だけ。首都を問う問題は作らない。
- 変えた js/css は index.html の `?v=` を「そのとき main にある数 +1」にする（tests/e2e/cache_bust.test.mjs）。
- 新しい色は作らない（今ある CSS 変数だけ）。
- 新しい localStorage のキーは profile.js の `TRANSFER_KEYS` か `LOCAL_KEYS` に入れる（tests/unit/transfer-keys.test.mjs）。端末ごとのものは `LOCAL_KEYS`。
- 新しい `emit()` のイベントは作らない（docs/events.md を増やさない）。
- 画面の文は日本語・ですます無しのやわらかい言い方（今の画面に合わせる）。
- 白地図のズームボタンを地図の外に出すのは**白地図タップだけ**・**幅600px未満だけ**。ほかの地図・PC は今のまま。
- 「アプリとして追加」の帯は**初めて来た日には出さない**・**×で30日出さない**・**アプリとして開いているときは出さない**。
- service worker は Supabase・Google Fonts・Google フォームなど**ほかのサイトへの通信にはさわらない**（`respondWith` しない）。
- e2e テスト: 途中は関係するテストだけ、PR を出す前に全部1回（テストファイルを4組に分けて4本同時に流す、約15分。ポートは0なので並べてよい）。4本同時で揺れる既知のテスト（rpg_gacha reveal_one_by_one・quiz_progress_coin_same_line・scenes_reach_their_screen）は単独で通れば良し。

## Review Focus

1. **service worker が古いファイルを出し続ける**: `?v=` の無い js（countries.js・trivia.js）を更新したのに、キャッシュの古い版が新しい index.html と混ざる → `?v=` 無しはネット優先にする。Task 4 の `sw_update_unversioned` で押さえる。
2. **service worker がテストの route を素通りさせる**: Playwright の route は service worker が出した通信を捕まえない → `openApp` は既定で service worker を止め、PWA のテストだけ `serviceWorkers: 'allow'`。Task 4 で helpers を直す。
3. **白地図の照準で、地図の外（海・地球の外）で Enter**: 今のタップと同じく × 印で不正解になり、エラーは出ない。Task 2 の `tap_keys_answer_sea` で押さえる。
4. **キー操作が入力欄・詳細の小窓を邪魔する**: 白地図にフォーカスがあるときだけ矢印・＋−・Enter を使う。ほかでは今までどおり。Task 2 の `tap_keys_only_when_focused`。
5. **iPhone の Safari（beforeinstallprompt が来ない）**: 帯の［追加する］で手順の小窓が出る。Task 6 の `install_banner_ios`。

**Interfaces:**
- Produces:
  - `tools/make_sw.mjs`: `export function swList(root) -> string[]`（precache の URL。ページからの相対、`?v=` 付きのものはそのまま）と `export function render(root) -> string`（できあがりの sw.js の全文）。`node tools/make_sw.mjs` で sw.js を書く。
  - `sw.js` の中の目印 `// precache:start` 〜 `// precache:end` のあいだに `const VERSION = '<sha256 の先頭12文字>'; const PRECACHE = [...];`。VERSION は PRECACHE の各ファイルの中身から作る（同じ入力ならいつも同じ）。
  - キャッシュ名 `drill-<VERSION>`。
  - `openApp(browser, { serviceWorkers = 'block', ... })` → `browser.newContext({ serviceWorkers })`。

- [ ] **Step 1: 失敗するテストを書く**（unit）
  - `sw_is_current`: `render(ROOT)` と今の `sw.js` が同じ（違えば「node tools/make_sw.mjs を流して」と出す）。
  - `sw_list_has_core`: `swList` に `./`・`index.html`・index.html が読む `*.js?v=`/`*.css?v=` の全部・`world.js?v=1`・`vendor/d3-7.9.0.min.js`・`vendor/topojson-client-3.1.0.min.js`・`countries.js`・`trivia.js`・`manifest.webmanifest`・`icons/icon-192.png`・国旗195枚（`flags/<a>.svg?v=<FLAG_V>`。`a` は countries.js の全部）・CSS の `url(textures/…)` が入っている。`admin.html`・`admin*.js`・`country/`・外のサイトの URL は入っていない。

  - `sw_version_follows_v`: 一時ディレクトリの index.html の `pc.css?v=` を上げて `render` すると、PRECACHE の `pc.css?v=` と VERSION が変わる（?v= を上げたら sw.js の作り直しが要る、を `sw_is_current` が捕まえられる）。
- [ ] **Step 2: 走らせて落ちるのを見る** — `node --test tests/unit/sw.test.mjs` が FAIL（make_sw.mjs が無い）。
- [ ] **Step 3: 実装**
  - `sw.js` の動き:
    - install: `PRECACHE` を全部 `cache.addAll`（失敗しても install は失敗させない：1つずつ add し、落ちたものはとばす）→ `skipWaiting()` はしない（遊んでいる途中で入れかえない）。

      - ページ（`request.mode === 'navigate'`）: ネット優先。3秒で返らないかネットが落ちたらキャッシュ（無ければ `index.html` のキャッシュ）。取れたものはキャッシュに入れる。
      - URL に `?v=` がある、または `vendor/` の下: キャッシュ優先、無ければネット→キャッシュに入れる。
      - それ以外: ネット優先、落ちたらキャッシュ。
  - `pwa.js`: `if ('serviceWorker' in navigator) addEventListener('load', () => navigator.serviceWorker.register('sw.js'))`（ページからの相対。英語版 PR で `<base>` を使っても同じ場所を指す）。
  - helpers の `openApp` に `serviceWorkers` を足す（既定 `'block'`）。
