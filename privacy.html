プライバシーポリシー

国旗マスター（このサイト）で、どんな情報をあつかうのかをまとめました。

集めるものと集めないもの

このサイトには、会員の登録はありません。登録しなくても、全部の遊びが使えます。

遊ぶために、本名・メールアドレス・住所・電話番号を集めることはありません。

お問い合わせで送られた内容（書いてくれたときはメールアドレスも）は、返事をするためだけに使います（送り先は Google フォームです）。

ランキングに記録をのせるときだけ、あなたが決めた名前と記録を送ります（くわしくは「ランキングに送るもの」）。

あなたの端末の中だけに保存するもの

遊んだ内容は、ふだんはあなたの端末（スマホやパソコンのブラウザ）の中だけに保存します。外に出るのは、あなたが自分で引き継ぎを使ったときだけです（くわしくは「引き継ぎ」）。

  • 設定（音・画面の色・出し方など）
  • 成績（まちがえた国、今日の難問の結果など）
  • 冒険の進み具合
  • バッジ
  • エラーの記録（うまく動かなかったときのメモ。これは引き継ぎのときも預けず、外には送りません）

ブラウザのサイトデータを消すと、これらも消えます。

ランキングに送るもの

ランキングにのせると決めたときだけ、次のものを送ります。送り先は Supabase というデータベースのサービスです。

プロフィール

  • 名前・公開するかどうか・いまつけている称号・かざり・取ったバッジの数を送ります。
  • プロフィールをあなたの端末と結びつけるために、端末が「合言葉」を作ります。サイトには合言葉そのものは残さず、元にもどせない形（ハッシュ）にしたものだけを保存します。

記録

のせる記録の種類は、タイムアタック・今日の難問・冒険の3つです。名前とタイム・正解の数・レベルなど、順位を決めるのに使う数を送ります。

非公開にしたとき

プロフィールを非公開にすると、プロフィールのカードには、名前・かざりと「このプロフィールは非公開だよ」というひとことだけが見えます。カードに称号やバッジの数、記録のまとめは出ません。

ランキングの表には、非公開でも名前と記録（タイムなど）がのります。

引き継ぎ

別の端末に引き継ぐときは、いまの端末のデータ（設定・成績・冒険・バッジなど。エラーの記録はのぞく）を預けて、引き継ぎのコードを出します。コードは24時間で使えなくなります。預けたデータは、そのあとの整理で消えます。

Supabase について

Supabase とやりとりするとき、Supabase の記録（ログ）に、あなたの通信の IP アドレスが残ることがあります。

名前のルール

ランキングの名前に、本名や学校名は使わないでください。人がいやな気持ちになる名前も使えません。

ルールに合わない名前や、おかしな記録があったときは、運営者が名前や記録を消したり、変えたりすることがあります。

消してほしいとき

ランキングの名前や記録を消してほしいときは、お問い合わせから送ってください。

消した記録は、まちがえて消したときのための控えに、しばらく残ることがあります。

使っている外のサービス

サイトを表示するために、次のサービスを使っています。ページを開くと、あなたのブラウザがこれらのサービスとやりとりします。

  • GitHub Pages（このサイトの置き場所）
  • Google Fonts（文字の形）
  • Google フォーム（お問い合わせ。送ったときだけ）

地図の部品（d3・topojson-client）はこのサイトの中に置いて配っています。そのため、地図を描くために外のサービスとやりとりすることはありません。

広告

このサイトでは、Google などの広告のサービスを利用する場合があります。

広告のサービスは、あなたの興味に合った広告を出すために、Cookie（クッキー）を使うことがあります。Cookie には、名前やメールアドレスなど、あなたがだれかが分かる情報はふくまれません。

あなたに合わせた広告を出さないようにするには、Google の広告設定で変えられます。Google が Cookie をどう使うかは、Google のポリシーと規約（広告）に書いてあります。

アクセス解析

このサイトでは、アクセス解析のサービス（何人が来たかなどを調べる道具）は使っていません。

このページの変更

このページの中身は、必要に応じて変えることがあります。変えたときは、このページでお知らせします。
